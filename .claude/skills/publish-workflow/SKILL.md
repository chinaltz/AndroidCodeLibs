# 文章发布全流程

一次性跑通博客文章从选题到发布就绪的完整流程。输入主题，输出一份可直接发布到公众号/知乎/掘金/个人博客的完整文章。

## 流水线步骤

按以下顺序依次执行，每步输出结果后再进入下一步：

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ ① 选题   │ → │ ② 初稿   │ → │ ③ 风格   │ → │ ④ 比喻   │
│ 确认方向 │   │ 生成正文 │   │ 优化语气 │   │ 注入比喻 │
└──────────┘   └──────────┘   └──────────┘   └──────────┘
                                                 ↓
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ ⑧ 发布   │ ← │ ⑦ 审查   │ ← │ ⑥ 配图   │ ← │ ⑤ 标题   │
│ 多平台版 │   │ 终审质检 │   │ 视觉方案 │   │ 选定标题 │
└──────────┘   └──────────┘   └──────────┘   └──────────┘
```

### ① 选题确认
向用户确认：
- 目标读者是谁？（参考 README.md 读者分层）
- 核心解决什么问题？
- 是否有特定角度或禁忌？

如用户未指定细节，根据主题自动推断并告知。

### ② 生成初稿
调用 /draft-post 的逻辑，生成完整初稿，严格遵循「技趣星球」写作模板。

### ③ 风格润色
调用 /improve-style 的逻辑：
- 术语翻译为日常语言
- 长句拆分
- 语气调整为对话感
- 加上「你」「我们」的亲近感

### ④ 比喻注入
调用 /create-metaphor 的逻辑：
- 为文中 2-3 个核心概念创建生活比喻
- 确保比喻覆盖目标读者的日常经验

### ⑤ 标题选定
调用 /generate-title 的逻辑：
- 按 5 种公式各出 1-2 个标题
- 推荐 TOP 3
- 让用户选定（或自动选最佳）

### ⑥ 配图方案
调用 /generate-images 的逻辑：
- 输出可直接嵌入的 ASCII 排版装饰
- 输出 AI 绘图提示词（Midjourney/即梦）
- 输出封面图方案

将这些视觉元素直接嵌入文章。

### ⑦ 终审质检
调用 /review-post 的逻辑：
- 5 条内容原则逐项检查
- 模板结构完整性检查
- 语气和可读性最终确认
- 输出修改优先级

### ⑧ 发布就绪
- 生成「公众号版」：含封面建议、摘要、话题标签
- 生成「知乎版」：含知乎话题标签、开头引导关注
- 生成「掘金版」：含技术标签、封面图
- 生成「个人博客版」：纯 Markdown，适合静态站点
- 将最终文章写入 `content/posts/[slug]/index.md`
- **生成公众号 HTML**：在 `content/posts/[slug]/index.html` 中生成富文本版，浏览器打开后点「一键复制正文」粘贴到公众号后台
- **多平台同步**：推荐使用 Wechatsync 插件（见下方「多平台发布方案」）

## 输出格式

最终输出包含：
1. **完整文章**（已写入文件）
2. **平台适配版本**（公众号/知乎/掘金/博客）
3. **配图清单**（哪些图需要制作，提示词已备好）
4. **发布检查清单**（发布前逐项确认）

## 多平台发布方案

### 方案 A：手动 HTML 复制（公众号首选）

1. 用浏览器打开 `content/posts/[slug]/index.html`
2. 点击顶部 **「一键复制正文」**
3. 到微信公众号后台 → 正文编辑区 → 粘贴
4. **图片需在公众号后台逐张上传**（本地路径公众号无法读取）

### 方案 B：Wechatsync 浏览器插件（多平台同步首选）

**工具**：[Wechatsync](https://github.com/wechatsync/Wechatsync)（开源 Chrome 插件，免费）

**支持平台**：微信公众号、知乎、掘金、简书、头条号、WordPress 等 10+ 平台

**安装步骤**：
1. Chrome 应用商店搜索「Wechatsync」安装，或从 GitHub Releases 下载 `.crx` 手动安装
2. 点击插件图标 → 登录各平台账号（一次性授权）
3. 打开文章 HTML 页面，点击插件 → 选择目标平台 → 一键同步

**注意事项**：
- 图片需提前上传到公众号素材库，Wechatsync 会自动匹配已上传图片
- 知乎/掘金支持直接上传本地图片
- 首次使用各平台需单独授权登录

### 方案 C：平台原生 Markdown 导入

| 平台 | 支持方式 |
|------|----------|
| 知乎 | 编辑器 → 导入 Markdown（支持） |
| 掘金 | 编辑器原生支持 Markdown |
| 个人博客 | 直接使用 `index.md` |
| 公众号 | 不支持 Markdown，用方案 A/B |

## 发布检查清单

- [ ] 标题是否吸引目标读者？
- [ ] 开头 3 句内能否让读者觉得「说的就是我」？
- [ ] 有无可直接复用的提示词/模板？
- [ ] 有无明确的小结和行动建议？
- [ ] 有无引流入口（关注回复/下期预告）？
- [ ] 配图是否齐全？封面是否适配移动端？
- [ ] 文中链接是否有效？
- [ ] 是否已适配目标平台格式？
