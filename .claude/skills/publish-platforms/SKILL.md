# 技趣星球 · 发布平台 Skill

> **维护约定**：与 `plan/01_内容平台清单.md`、`plan/平台注册进度追踪.html` 同步。变更后见 `.claude/skills/sync-context/SKILL.md` 与根目录 `CONTEXT.md`。

博客 **仅维护第一梯队 + 第二梯队** 共 **13** 个主平台。

## 第一梯队（必注，4 个）

| 平台 | 地址 | 发布要点 |
|------|------|----------|
| 微信公众号 | https://mp.weixin.qq.com/ | 私域核心；正文用 `index.html` 一键复制；图片需上传素材库 |
| 知乎 | https://www.zhihu.com/ | 支持导入 Markdown；加话题标签与关注引导 |
| 掘金 | https://juejin.cn/ | 原生 Markdown；技术标签 + 封面图 |
| CSDN | https://www.csdn.net/ | 代码高亮需适配；SEO 长尾 |

## 发布顺序建议

```
微信公众号（首发）
    → 知乎 + 掘金 + CSDN（同日或次日技术圈）
    → 简书 + 头条 + 百家号（泛流量）
    → 思否 + 博客园（技术长尾）
    → 小红书 + 网易号（短图文/要点版）
    → 抖音 + 快手（竖屏脚本 + 封面，可同源）
```

## 多平台同步工具

| 工具 | 适用 | 说明 |
|------|------|------|
| Wechatsync | 公众号、知乎、掘金、简书、头条等 | Chrome 插件，见 `publish-workflow` |
| 简媒 | 国内 30+ 平台 | 一键分发，新手友好 |
| 壹伴 | 公众号为主 | 编辑 + 多平台导出 |
| 手动 | 小红书、网易号、抖音、快手 | 需单独改标题、封面比例与时长 |

## 各平台格式速查

| 平台 | Markdown | 图片/视频 | 特殊注意 |
|------|----------|-----------|----------|
| 公众号 | ❌ | 素材库上传 | 用 HTML 复制正文 |
| 知乎 | ✅ 导入 | 编辑器上传 | 版权声明 |
| 掘金 | ✅ | 编辑器上传 | 技术标签必填 |
| CSDN | 部分 | 编辑器上传 | 代码块格式 |
| 简书/博客园 | ✅ | 编辑器 | 标准 Markdown |
| 头条/百家号/网易号 | 富文本 | 封面 16:9 等 | 标题吸引点击 |
| 思否 | ✅ | 编辑器 | 偏技术深度 |
| 小红书 | ❌ | 竖图 3:4 | 短句 + 话题标签 |
| 抖音/快手 | ❌ | 竖屏 9:16 | 60–180 秒脚本或图文卡；勿贴长文 |

## 发布检查清单（平台相关）

- [ ] 第一梯队 4 平台是否已登录/授权（Wechatsync 一次性）
- [ ] 公众号封面与正文图片是否已上传素材库
- [ ] 掘金/CSDN/知乎 技术标签是否一致
- [ ] 小红书是否已改写为「要点卡片」
- [ ] 抖音/快手是否有竖屏封面与口播/字幕脚本
- [ ] 各平台封面尺寸是否分别处理

## 账号进度追踪

打开 `plan/平台注册进度追踪.html` 记录注册状态（localStorage，可导出 JSON）。

## 与 publish-workflow 的关系

执行 `/publish-workflow` 第 ⑧ 步时：

1. 默认输出：公众号版、知乎版、掘金版、个人博客版
2. 全平台需求：为第二梯队各生成摘要版或格式提示（含抖音/快手脚本要点）
3. 不主动推荐已移除的海外/第三梯队平台
