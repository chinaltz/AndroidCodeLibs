# 概念比喻转化器

将一个AI技术概念转化为非技术人群能秒懂的日常生活比喻。

## 转化框架

对每个概念，按以下结构输出：

### 1. 一句话人话版
用不超过25个字说清这个东西到底是什么。
格式：`[概念名]其实就是[做什么的]。`

### 2. 核心比喻（必出1个）
找一个日常生活中的对应物来比喻。要求：
- 必须是普通人每天可能接触的事物或角色
- 比喻要覆盖概念的核心特征（不是所有特征）
- 比喻本身不需要解释（"像实习生"不需要解释什么是实习生）

已有的成功比喻参考：
- 大模型 → 读过海量资料的超级实习生
- Prompt → 给AI下任务的任务说明书
- Token → AI眼里的文字小颗粒
- RAG → 给AI带一本参考书再回答
- Agent → 能自己分步骤办事的AI助手
- 多模态 → AI开始长眼睛和耳朵了
- 微调 → 给AI定向补课
- 推理 → 一步步想问题
- 幻觉 → 一本正经地编造

### 3. 一个场景故事（可选但推荐）
用50-80字写一个小场景，让读者在故事里理解这个概念。

### 4. 边界说明
用1句话说明这个比喻的局限（什么情况下这个比喻不太对）。

## 可供使用的比喻来源库

日常角色：实习生、秘书、助手、翻译、图书管理员、厨师、裁缝、导游
日常物品：菜谱、地图、积木、橡皮泥、计算器、复读机
日常场景：做饭、装修、导航、查字典、拼乐高、传话游戏

## 输出格式

```markdown
## [概念名]

**一句话人话版**：[一句话]

**核心比喻**：
把[概念名]想象成[日常事物/角色]。它[核心行为/特征]。

**场景故事**（可选）：
[50-80字场景描述]

**类比边界**：
这个比喻不太对的地方是：[一句话]
```

## 注意事项

- 比喻不是解释，是帮助理解。不需要100%精确。
- 优先使用中文语境中的日常事物（用"菜谱"不用"食谱"，用"装修"不用"renovation"）
- 如果一个概念需要多步骤比喻才能说清，用一个比喻说核心，附带补充说明
- 如果概念特别复杂，可以给出2个不同角度的比喻供选择
