# 技趣星球 · 蓝天星球文章风格

## 风格来源

融合三类参考：

- `animal-island-ui`：借鉴圆润控件、厚边框、胶囊按钮、轻微硬阴影，但不照搬岛屿/木色主题。
- `BaseWidget` 本地 token：`/Users/litingzhe/Documents/BaseWidget/design/tokens/color_token.json` 与 `style_token.json`。
- 技趣星球定位：面向普通人的技术实操教程，轻松、可上手、不制造焦虑。

## 核心气质

- 像一本“蓝天星球旅行手册”：蓝天白云做氛围，正文落在干净明亮的白色纸面上。
- 用天蓝、淡蓝、云白、恒星黄表达“美好、轻松、可上手”，紫色不作为主色。
- 圆润、清爽、有亲和力；不要做成深色科幻屏，也不要做成复杂游戏界面。
- 参考岛屿 UI 的亲和力，但视觉母题改成“星球、轨道、云朵、晴空、轻量控制台”。

## 颜色规范

优先使用这组语义色，不直接写一堆新颜色：

| 用途 | 颜色 | 语义 |
|------|------|------|
| 页面底 | `#DDF4FF` → `#F9FDFF` | 蓝天白云背景 |
| 文章纸面 | `#FFFFFF` | 星尘纸面 |
| 云朵纸面 | `#FEFFFF` | 白云卡片 |
| 次级纸面 | `#F6FBFF` | 浅云蓝 |
| 边框 | `#C8EAFF` / `#E4F5FF` | 淡蓝云边 |
| 主强调 | `#31A8FF` | 天蓝星球 |
| 强调深色 | `#1479D6` | 深天蓝 |
| 辅助强调 | `#8BD5FF` | 浅天蓝 |
| 高亮 | `#FFD166` / `#FFF7D7` | 阳光黄 |
| 行动/链接 | `#43CFC7` | 清爽青 |
| 正文 | `#365D82` | 蓝灰正文 |
| 标题 | `#173A62` | 深蓝标题 |
| 警示 | `#FF6B7A` | 彗星红 |

正文不能整屏深色，也不要大面积蓝紫渐变，否则公众号阅读疲劳。做法是：页面背景蓝天白云，文章主体用白色/云白纸面承载内容。

## 排版规范

- 正文：16px，行高 1.85-1.95，颜色 `#365D82`。
- H1：白色到浅云蓝纸面，24px，粗体，圆角 30，2px 淡蓝云边，轻量云朵阴影。
- H2：白色到浅云蓝胶囊标题，19px，左侧天蓝圆点；不要用强色块。
- H3：深蓝小标题，左侧阳光黄小点。
- 段落重点：用阳光黄下划高亮，少用整块荧光色。
- 引用/提示框：云白纸面 + 2px 淡蓝云边；tip 用清爽青，warning 用阳光黄/彗星红。
- 表格：外层云白卡片，表头浅蓝底深蓝字，单元格白/浅云蓝交替；内线用 1px 淡云蓝，避免厚重。
- 代码块：云白底、深蓝字、24px 圆角、淡蓝云边。
- 图片：24-26px 圆角，2px 淡蓝云边，白色外光晒。
- 跨平台正文**禁止使用 ASCII/Unicode 字符边框**，包括：`╔═╗`、`┌─┐`、`└┘`、长串 `====`、`━━━━` 等。不同平台字体宽度不同，常过宽错位。替代方案：
  - **流程/层级关系**：用 Markdown 引用块（`>`）配合 `↓` 符号与加粗文字，不用字符边框包裹。示例：
    ```markdown
    > **你（提需求）**
    > ↓
    > **MiMo Code**（理解 → 规划 → 执行）
    > ↓
    > **你的项目文件**（被修改、运行）
    ```
  - **强调标注块**：用 `>` 引用块、普通小标题、表格或导出 HTML 的提示框样式。
  - **转换关系**：直接用文字 + 句内 `→` 符号即可，无需字符框。

## 文章结构用法

优化文章时优先使用：

1. 首屏：标题 + 头图 + 一句话结论 + 关注/回复口令。
2. 正文：短段落、表格、引用块/提示块，少用长解释。不要用字符边框做装饰。
3. 转化：开头和结尾都出现“关注微信公众号 AI技趣星球，回复MF 一起用技术创造乐趣。”。
4. 风险：涉及科学上网、海外模型、订阅地址时保留学习用途和合规提醒。
5. 结尾：给一个可复制的提示词或立刻能做的小动作。

## 公开正文命名规范

- 面向读者的文章正文里，默认去掉平台品牌前缀，除非必须区分具体平台操作。
- 带平台品牌前缀的“小程序/公众号/开发者工具”统一去掉品牌前缀，写成“小程序”“公众号”“小程序开发者工具”。
- 关注引导是固定例外，统一写成：“关注微信公众号 AI技趣星球，回复MF 一起用技术创造乐趣。”
- 发布流程、平台清单、技术排障等必须精确指代平台的内部文档，可以保留完整平台名。

## 配图规范

- 公众号头图：优先 16:9，2560×1440；蓝天白云、明亮星球、轻轨道、少量阳光黄高亮。
- 信息图/小红书卡片：云白纸面、天蓝主按钮、阳光黄重点、深蓝正文。
- 小红书：1080×1440，3:4，8 张以内，卡片标题大，正文少。
- **微信搜一搜 / 看一看 PNG 卡片**：禁止出现关注、公众号、回复等导流词（完整禁词表见 `generate-images` SKILL）；关注口令只写在 `UPLOAD.md` 的公众号长文区块，不进 PNG。
- 抖音/快手：1080×1920，9:16，33-60 秒，底部 CTA 不超过 4 行。

## 编码迁移

如果把这套风格用于前端/Android：

- 把颜色先抽成 semantic tokens，不在组件里写裸色。
- Button 使用 pill 圆角、2px 边框、4-5px 硬阴影，pressed 时阴影缩小。
- Card 使用 24/30px 圆角、2px 淡蓝云边、云白纸面背景。
- Modal 可用 organic blob；不方便时用 36px 大圆角 fallback。
- Tabs/Chip 使用 pill；active 用天蓝、浅天蓝或阳光黄。

## 检查清单

- [ ] 页面是否读起来像蓝天星球旅行手册，而不是普通 Markdown？
- [ ] 页面是否有蓝天白云的干净明亮感，正文是否足够易读？
- [ ] 主色是否是天蓝/淡蓝/云白，黄色和青色只做点缀？
- [ ] 重点是否有高亮，但没有过度花哨？
- [ ] 表格、代码、引用是否都套了圆角卡片？
- [ ] 关注/回复口令是否在开头和结尾闭环？
- [ ] 科学上网相关表述是否保留学习用途和合规提醒？
