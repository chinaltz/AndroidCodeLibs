# 技趣星球 · 发布平台 Skill

> **维护约定**：与 `plan/01_内容平台清单.md` 同步。变更后见 `sync-context` SKILL。

博客 **当前仅维护 4 个发布平台**：**微信公众号、微博、知乎、CSDN**。

## 发布策略

**四平台发同一篇全文。** 不生成短讯版、不生成平台专属简版、不写跨平台导流句。

## 当前发布平台

| 平台 | 地址 | 说明 |
|------|------|------|
| 微信公众号 | https://mp.weixin.qq.com/ | `index.html` 一键复制全文 |
| 微博 | https://weibo.com/ | 粘贴全文 |
| 知乎 | https://www.zhihu.com/ | Markdown 导入全文 |
| CSDN | https://www.csdn.net/ | 粘贴全文，保留代码块 |

## 正文违禁表述

以下**不得**出现在公开正文：

- `详情见公众号`、`见公众号「…」`、`详情见链接`
- `关注 AI技趣星球`、`关注微信公众号`、`回复 XX`
- 微博短讯体 + 外链引流

**允许落款**（文首引用块 + 文末）：

```
技趣星球 · 用技术创造乐趣。
```

## 发布检查清单

- [ ] 正文无跨平台导流违禁词
- [ ] 文首、文末仅有「技趣星球 · 用技术创造乐趣。」
- [ ] 四平台粘贴**同一篇**全文（仅格式差异）
- [ ] 公众号封面与正文图已上传素材库
- [ ] 未生成掘金/小红书/抖音等已暂停平台内容

## 与 publish-workflow 的关系

执行 `/publish-workflow` 第 ⑧ 步时，默认输出 **一篇** 四平台通用正文 + 发布检查清单，**不**单独输出微博短讯、知乎简版等。
