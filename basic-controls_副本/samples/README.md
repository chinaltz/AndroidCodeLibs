# Basic Controls Samples

所有端的 samples 都按根目录 `component_contract.json` 覆盖 API：

- Android View：`android/basiccontrols/samples`
- 微信小程序：`android/basiccontrols/miniprogram/pages/basic-samples`
- Kuikly：`android/basiccontrols/kuikly/shared/src/commonMain/kotlin/com/techskillplanet/phonics/samples`
- iOS SwiftUI：`ios/BasicControls/Samples`
- Flutter：`flutter/basic_controls/example`
- React Native：`react-native/base-widgets/src/starPlanet/sample`
- React Web：`web/react/sample/index.html`
- Vue Web：`web/vue/sample/index.html`

样例目标是同一套星球主题、同一套组件语义、同一组 API 状态。复杂平台能力组件按端能力实现，但视觉和 API 名称保持一致。
