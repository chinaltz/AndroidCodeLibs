# 技趣星球

用技术创造乐趣，让每个人都能做出自己的作品。

## 博客定位

不讲高深理论，只做「可上手」的技术教程。用 AI + 各类工具，帮普通人做出 App、网页、小工具、音乐、视频、特效……从零到成品，步步拆解。

## 适合谁看

- 想用 AI 做点东西但不知道从哪开始的人
- 对技术好奇但不想啃书的人
- 想学翻墙、用工具、提升效率的人
- 喜欢动手实操、不爱看纯理论的人

## 内容方向

| 方向 | 说明 |
|------|------|
| AI 实操 | AI 能帮你做什么？怎么一步步做出来 |
| 工具指南 | 好用的工具怎么装、怎么用 |
| 案例教程 | 从零做出一个成品（App/网页/音乐/视频） |
| 福利分享 | 工具资源、提示词模板、限免信息 |
