# 音标星球二期 · 产品分析、原型与需求文档

## 1. 产品定位

二期从“音标学习工具”扩展成“家里可持续使用的小学生默写练习工具”。

核心变化：

- 从单人进度变成多孩子本地档案。
- 从只学音标变成音标 + 生字 + 错字 + 听写提醒。
- 从只在小程序里练习，扩展到可保存 A4 默写纸，方便打印或手写。

边界必须明确：

- 不做账号。
- 不做登录。
- 不做云同步。
- 不上传孩子信息。
- 孩子昵称只保存在本机微信小程序本地缓存，用于区分不同孩子的学习数据。

## 2. 目标用户与场景

### 2.1 用户

学生：

- 小学低年级到中年级。
- 需要练音标、拼音、生字和错字。
- 一次练习注意力大约 5-15 分钟。

家长：

- 希望快速记录孩子不会的字。
- 希望知道哪些字错得多。
- 希望隔几天提醒复习。
- 希望能生成一张纸，让孩子离开屏幕默写。

### 2.2 典型场景

1. 家里两个孩子都用同一个小程序，进度不能混在一起。
2. 家长听写时发现孩子写错“慢”，希望一键加入错字本。
3. 同一个字又错一次，系统不重复新建，而是错误次数 +1。
4. 某批字已经很多天没听写，小程序首页提醒“该复习了”。
5. 家长想把本周错字生成 A4 默写纸，保存为图片、Word 或 PDF。

## 3. 产品原则

- 本地优先：所有数据默认只在小程序本地保存。
- 低打扰：提醒只在小程序内展示，不做强推送。
- 少输入：家长只输入字和可选拼音，系统尽量自动补齐。
- 可打印：导出内容以 A4 纸为目标，不只是截图好看。
- 分孩子：孩子切换是首页一级能力，不藏在设置里。

## 4. 信息架构

```text
首页
  ├─ 孩子切换
  ├─ 当前孩子学习概览
  ├─ 音标学习入口
  ├─ 生字积累入口
  ├─ 错字本入口
  └─ 听写提醒入口

孩子管理
  ├─ 新增孩子
  ├─ 修改昵称
  ├─ 切换当前孩子
  └─ 删除本地孩子数据

生字积累
  ├─ 新增生字
  ├─ 拼音
  ├─ 分组/来源
  ├─ 掌握状态
  └─ 加入听写

错字本
  ├─ 错字列表
  ├─ 错误次数
  ├─ 最近错误时间
  ├─ 再错一次
  └─ 标记已掌握

听写
  ├─ 今日建议
  ├─ 久未复习
  ├─ 选择字词
  ├─ 生成默写纸
  └─ 记录结果
```

## 5. 核心原型说明

可交互原型路径：

```text
prototypes/phonics-learning-planet-v2/index.html
```

原型覆盖 5 个主视图：

- 首页：孩子切换、当前进度、提醒和主要入口。
- 孩子：新增孩子昵称，说明仅本地保存。
- 生字：新增生字、拼音、来源和加入听写。
- 错字：错字次数、又错一次、已掌握。
- 默写纸：A4 排版预览，导出图片、Word、PDF 的产品入口。

## 6. 功能需求

### 6.1 绑定孩子

目标：让家里多个孩子的数据互不混淆。

入口：

- 首次打开时，如果没有孩子档案，展示“添加孩子”引导。
- 首页顶部展示当前孩子，可点击切换。
- 设置页保留孩子管理入口。

字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 孩子昵称 | 是 | 只用于本地区分，如“小宝”“姐姐” |
| 创建时间 | 自动 | 本地生成 |
| 当前孩子标记 | 自动 | 用于首页默认展示 |

交互规则：

- 昵称 1-12 个中文、英文、数字或空格。
- 空昵称不可保存。
- 重名允许，但保存时提示“只是本地区分，建议换个更好认的昵称”。
- 新增第一个孩子后自动设为当前孩子。
- 删除当前孩子后，自动切到列表中第一个孩子；没有孩子时回到添加引导。

隐私提示文案：

```text
昵称只保存在这台设备里，用来区分不同孩子的进度。小程序没有账号，也不会上传任何孩子信息。
```

验收标准：

- 没有孩子时，不能进入学习数据页，必须先添加一个本地孩子。
- 切换孩子后，音标进度、生字、错字、听写记录全部随孩子切换。
- 清理微信小程序缓存后，本地孩子数据会消失，产品文案需要让家长知道这一点。

### 6.2 首页孩子切换

首页顶部固定展示：

- 当前孩子昵称。
- 今日建议。
- 孩子切换按钮。

首页模块：

- 学习进度：音标完成数、待复习字数、错字数。
- 听写提醒：超过复习间隔的字词。
- 快捷入口：音标学习、生字积累、错字本、生成默写纸。

切换规则：

- 点击当前孩子区域弹出本地孩子列表。
- 选中孩子后刷新首页所有统计。
- 切换只影响当前设备，不影响其他设备。

### 6.3 生字积累

目标：记录孩子需要反复练的汉字或词语。

字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 内容 | 是 | 单字或词语，建议 1-8 个字 |
| 拼音 | 否 | 可自动生成，也允许家长手动改 |
| 来源 | 否 | 如“语文课本”“听写”“家长添加” |
| 分组 | 否 | 如“一年级上”“本周” |
| 掌握状态 | 自动 | 新增默认为待练 |
| 创建时间 | 自动 | 本地生成 |
| 最近练习时间 | 自动 | 听写后更新 |

核心操作：

- 新增生字。
- 编辑拼音。
- 加入听写。
- 标记已掌握。
- 从生字转为错字。

验收标准：

- 同一孩子下，重复添加同一个字时，提示“已存在”，允许更新拼音和来源。
- 不同孩子可以有相同生字，互不影响。
- 拼音生成失败时，不阻塞保存，显示“可稍后补拼音”。

### 6.4 错字本

目标：把“错过的字”变成可复习、可统计、可导出的练习材料。

字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 内容 | 是 | 错字或词语 |
| 拼音 | 否 | 用于默写纸提示 |
| 错误次数 | 自动 | 首次加入为 1 |
| 最近错误时间 | 自动 | 每次再错更新 |
| 来源 | 否 | 例如“第 3 单元听写” |
| 状态 | 自动 | 待练、复习中、已掌握 |

新增规则：

- 从听写结果标记错字：如果错字不存在，新增并设错误次数为 1。
- 手动新增错字：同样错误次数为 1。
- 如果同一个孩子同一个内容再次写错，不新建重复项，只执行错误次数 +1，并更新最近错误时间。

核心操作：

- 又错一次：错误次数 +1。
- 标记已掌握：从待练列表移出，但保留历史。
- 恢复练习：已掌握后再次加入待练。

验收标准：

- 错误次数排序默认从高到低。
- 错字详情能看到错误次数和最近错误时间。
- 生成默写纸时可选择“只导出错字”“错字 + 生字”。

### 6.5 听写提醒

目标：提醒家长不要隔太久才复习。

提醒规则：

- 新增生字或错字后，默认 3 天未练习进入“该复习”。
- 错误次数 >= 3 的字，默认 1 天未练习进入“重点复习”。
- 已掌握的字默认不提醒，除非家长手动恢复。

首页展示：

- “3 个字该复习了”
- “2 个高频错字建议今天听写”
- 展示前 5 个字，更多进入听写页。

不做事项：

- 首版不接微信订阅消息。
- 首版不做后台定时通知。
- 首版只做打开小程序后的本地提醒。

验收标准：

- 每个孩子的提醒独立计算。
- 修改孩子后提醒数量立刻刷新。
- 听写完成后，相关字词的最近练习时间更新，提醒消失或降级。

### 6.6 生成 A4 默写纸

目标：用拼音和字词生成适合保存、打印、手写的默写练习纸。

输入：

- 选择孩子。
- 选择范围：生字、错字、重点错字、本周新增、自定义勾选。
- 是否显示拼音。
- 是否显示字格。
- 每页字数：12、16、20、24。

输出：

- 图片：适合直接保存到相册或微信转发。
- Word：适合家长二次编辑。
- PDF：适合打印。

A4 排版要求：

- 纸张比例按 A4 竖版：210mm x 297mm。
- 上方包含标题、孩子昵称、日期。
- 每个字词占一个稳定练习块。
- 拼音在上，默写格在下。
- 每行 2 或 3 个练习块，手机预览时按比例缩放。
- 留出打印边距，避免内容贴边。
- 字格和下划线要清晰，不能太浅。

验收标准：

- 生成 12、16、20、24 个字时，页面都不溢出。
- 长词超过 4 个字时自动使用横向练习块，避免挤压。
- 图片导出清晰度不低于 1240 x 1754。
- Word/PDF 导出失败时，至少能退化保存图片。

## 7. 非功能需求

数据：

- 所有数据保存在微信小程序本地缓存。
- 数据结构需带版本号，方便后续迁移。
- 需要提供“导出本地数据”和“清空当前孩子数据”的能力。

体验：

- 首页切换孩子后 300ms 内完成刷新。
- 生字/错字新增流程不超过 2 个页面。
- 每个主操作按钮文案必须是动作，不使用抽象术语。

兼容：

- 微信小程序基础库不低于现有项目要求。
- iPhone 小屏、iPad 微信、安卓主流机型都要检查 A4 预览缩放。

## 8. 版本规划

### V2.0 首版

- 本地孩子档案。
- 首页孩子切换。
- 生字积累。
- 错字本。
- 久未听写提醒。
- A4 默写纸图片导出。

### V2.1

- Word/PDF 导出。
- 拼音自动生成优化。
- 听写结果批量录入。
- 数据导入导出。

### V2.2

- 自然拼读词库。
- 更细的复习算法。
- 微信订阅消息提醒，前提是家长明确授权。

## 9. 待确认问题

- 拼音自动生成是否允许引入本地拼音词库，还是首版只做手动输入 + 简单多音字提示。
- Word/PDF 是否必须在小程序端离线生成，还是允许先用图片导出满足主要场景。
- 默写纸是否需要支持田字格、拼音格、四线三格三种模板。
