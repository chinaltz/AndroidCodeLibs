# 音标星球二期 · 产品分析、原型与需求文档

## 1. 产品定位

二期从“音标学习工具”扩展成“家里可持续使用的小学生默写练习工具”。

核心变化：

- 从单人进度变成多孩子本地档案。
- 从只学音标变成音标 + 生字 + 错字 + 听写提醒。
- 从只在小程序里练习，扩展到可保存 A4 默写纸，方便打印或手写。

边界必须明确：

- 不做账号。
- 不做登录。
- 不做云同步。
- 不上传孩子信息。
- 孩子昵称只保存在本机微信小程序本地缓存，用于区分不同孩子的学习数据。

## 2. 目标用户与场景

### 2.1 用户

学生：

- 小学低年级到中年级。
- 需要练音标、拼音、生字和错字。
- 一次练习注意力大约 5-15 分钟。

家长：

- 希望快速记录孩子不会的字。
- 希望知道哪些字错得多。
- 希望隔几天提醒复习。
- 希望能生成一张纸，让孩子离开屏幕默写。

### 2.2 典型场景

1. 家里两个孩子都用同一个小程序，进度不能混在一起。
2. 家长听写时发现孩子写错“慢”，希望一键加入错字本。
3. 同一个字又错一次，系统不重复新建，而是错误次数 +1。
4. 某批字已经很多天没听写，小程序首页提醒“该复习了”。
5. 家长想把本周错字生成 A4 默写纸，保存为图片、Word 或 PDF。
6. 家长把老师发的听写语音转成文字，从里面选择要练的词语。
7. 家长拍一张作业或课本生字页，从识别文字里勾选本次要听写的词。
8. 词语超过一个字时，家长需要标明“整个词都不会写”还是“只某个字不会写”。
9. 开始听写时，小程序自动把字词播报出来，并支持设置每个词之间的间隔。

## 3. 产品原则

- 本地优先：所有数据默认只在小程序本地保存。
- 低打扰：提醒只在小程序内展示，不做强推送。
- 少输入：家长只输入字和可选拼音，系统尽量自动补齐。
- 可打印：导出内容以 A4 纸为目标，不只是截图好看。
- 分孩子：孩子切换是首页一级能力，不藏在设置里。

### 4.1 字与词的关系

“不会的字”和“听写词”不能使用同一条数据表示：

- **不会字**：最小复习对象，记录错误次数、最近错误时间、掌握状态。
- **听写词**：最小播报对象，必须是可直接听写的完整字或词语。
- **关联关系**：一个听写词可关联多个不会字，一个不会字也可关联多个听写词。

示例：

```text
不会字「候」
  ├─ 关联听写词「时候」
  └─ 关联听写词「等候」

听写词「时候」
  └─ 关联不会字「候」
```

录入规则：

1. 家长可以一次粘贴或输入多个听写词，使用空格、逗号、顿号或换行分隔。
2. 输入后将所有字以灰色字块平铺展示，录入页不要求选择课文来源。
3. 家长按点击顺序选择字，所选字依次追加到下方判断区。
4. 每个字必须明确选择“会”或“不会”，未选择时保持灰色待处理状态。
5. 一个词开始处理后，必须把该词的全部字加入判断区。例如“时候”需要同时包含“时”和“候”。
6. 只有所涉及词语的全部字都已加入，并且每个字都完成“会 / 不会”选择，才显示保存按钮。
7. 点击保存后，按完整词语写入已保存词汇和生字词库，不按单字拆成多条听写词。
8. 标记为“不会”的字进入不会字库，并与当前完整听写词建立关联。
9. 全部标记为“会”时，完整词仍保存为“仅听写”词。
10. “又错一次”增加关联不会字的错误次数，不重复创建字记录。

交互示例：

```text
输入：时候
点击「时」 → 判断区出现：时 [会] [不会]
点击「候」 → 在“时”后追加：候 [会] [不会]
选择：时=会、候=不会
点击保存 → 已保存词汇增加“时候”，不会字库增加“候”
```

## 5. 核心原型说明

可交互原型路径：

```text
prototypes/phonics-learning-planet-v2/index.html
```

原型覆盖 5 个主视图：

- 首页：孩子切换、当前进度、提醒和主要入口。
- 孩子：新增孩子昵称，说明仅本地保存。
- 生字：字词星球内统一“添加”入口，子页面选择手动或按课本添加。
- 手动录入：支持一次输入多个词，按点击顺序逐字判断会/不会；不填写来源，保存时自动生成参考拼音。
- 课本听写：在字词星球内按年级、册别、单元、课文选择生字和课内/不超纲生词。
- 智能录入：语音/图片识别结果进入多文本确认页，从候选里选择字词，后续版本再做，本期不实现。
- 听写播报：字词转语音，支持词语间隔、重复次数和读音速度。
- 听写批改：播报完成后逐词标记正确/错误；错误词继续选择具体错字，保存后更新不会字统计。
- 错字：错字次数、又错一次、已掌握。
- 默写纸：A4 排版预览，导出图片、Word、PDF 的产品入口。

### 5.1 当前实现版本说明

本期优先完成可验证的闭环：

- 首页从原型列表升级为少儿游戏化主屏：冒险 Banner、今日任务、星球地图、关键学习数据。
- 课本听写入口放在字词星球内，不作为首页独立星球入口。
- 字词星球顶部同时保留“手动录入”和“课文听写”快捷入口。
- 课文听写支持 1-6 年级、上下册选字，可保存到字词库或直接开始听写。
- 字词星球统一添加入口，当前只做手动录入和课本选择；语音录入、拍照录入后续版本再做。
- 全部生词支持按周分组、搜索、勾选字词、听写本周和听写已选。
- 听写列表统一承接课文、错词和字词库选词，支持开始前增删改。
- 听写播放支持词语间隔和重复次数，语音实现不在产品页面暴露厂商信息。

视觉方向：

- 首页避免“功能列表”形态，改成孩子能理解的星球冒险地图。
- 优先复用现有专业 PNG 插画资源，如孩子头像、学习星球、音标星球、字词星球。
- 卡片用于任务和星球入口，不再用大段说明文堆叠页面。
- 关键操作按钮保持明确：开始、听写、配置、添加。

## 6. 功能需求

### 6.1 绑定孩子

目标：让家里多个孩子的数据互不混淆。

入口：

- 首次打开时，如果没有孩子档案，展示“添加孩子”引导。
- 首页顶部展示当前孩子，可点击切换。
- 设置页保留孩子管理入口。

字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 孩子昵称 | 是 | 只用于本地区分，如“小宝”“姐姐” |
| 创建时间 | 自动 | 本地生成 |
| 当前孩子标记 | 自动 | 用于首页默认展示 |

交互规则：

- 昵称 1-12 个中文、英文、数字或空格。
- 空昵称不可保存。
- 重名允许，但保存时提示“只是本地区分，建议换个更好认的昵称”。
- 新增第一个孩子后自动设为当前孩子。
- 删除当前孩子后，自动切到列表中第一个孩子；没有孩子时回到添加引导。

隐私提示文案：

```text
昵称只保存在这台设备里，用来区分不同孩子的进度。小程序没有账号，也不会上传任何孩子信息。
```

验收标准：

- 没有孩子时，不能进入学习数据页，必须先添加一个本地孩子。
- 切换孩子后，音标进度、生字、错字、听写记录全部随孩子切换。
- 清理微信小程序缓存后，本地孩子数据会消失，产品文案需要让家长知道这一点。

### 6.2 首页孩子切换

首页顶部固定展示：

- 当前孩子昵称。
- 今日建议。
- 孩子切换按钮。

首页模块：

- 学习进度：音标完成数、待复习字数、错字数。
- 听写提醒：超过复习间隔的字词。
- 快捷入口：音标学习、生字积累、错字本、生成默写纸。

切换规则：

- 点击当前孩子区域弹出本地孩子列表。
- 选中孩子后刷新首页所有统计。
- 切换只影响当前设备，不影响其他设备。

### 6.3 生字积累

目标：记录孩子需要反复练的汉字或词语。

补充：产品入口仍统一叫“字词”，但数据层拆为“不会字”和“听写词”，通过关联关系连接。

字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 内容 | 是 | 单字或词语，建议 1-8 个字 |
| 拼音 | 否 | 自动生成参考拼音，允许家长手动改 |
| 来源 | 否 | 如“语文课本”“听写”“家长添加” |
| 分组 | 否 | 如“一年级上”“本周” |
| 周分组 | 自动 | 按创建时间归入“本周、上周、YYYY 第 NN 周” |
| 教材来源 | 否 | 如“一年级上 · 第一单元 · 第一课” |
| 错误次数 | 自动 | 新增默认为错 1 次 |
| 掌握状态 | 自动 | 新增默认为待练 |
| 创建时间 | 自动 | 本地生成 |
| 最近练习时间 | 自动 | 听写后更新 |

核心操作：

- 新增生字。
- 编辑拼音。
- 加入听写。
- 标记已掌握。
- 从生字转为错字。
- 从内置教材生字库选择某一课的字词快速添加。
- 按周查看全部生词。
- 搜索全部生词。
- 按周发起听写或生成默写纸。
- 勾选任意字词后发起听写。

验收标准：

- 同一孩子下，重复添加同一个字时，提示“已存在”，允许更新拼音和来源。
- 不同孩子可以有相同生字，互不影响。
- 拼音生成失败时，不阻塞保存，显示“可稍后补拼音”。
- 手动录入词语时，每个字必须明确标记“会”或“不会”。
- 只选择词语中的部分字时不能保存，必须选择并判断完整词语的所有字。
- 保存按钮只在全部已选字完成判断后出现。
- 保存后完整词进入字词库，“不会”的字进入不会字库并建立关联。
- 新增字词默认 `wrongCount = 1`，直接进入待复习/听写候选。
- 字词星球必须有“全部生词 · 按周分组”列表，不受“待复习/高频错字”筛选限制。
- 每个周分组能展示数量、待练数量和词语预览。
- 全部生词列表支持按汉字、词语、拼音、课文来源搜索。
- 搜索结果和周分组里的字词都能被勾选，已选字词可直接进入听写。

### 6.3.1 内置教材生字库

目标：内置小学 1-6 年级人教版/统编版语文生字列表，方便家长按“年级、册、单元、课文”添加字词来源。

数据边界：

- 首版先做本地 JSON，不依赖网络。
- 每个字词记录年级、册别、单元、课文、拼音、声调。
- 正式内置前必须按实际教材版本逐课核对。
- 不在需求文档里伪造全量教材内容；全量数据需要单独录入、校对和授权确认。

来源选择交互：

- 添加字词页展示“教材来源”选择器。
- 选择来源后展示本课生字 chip。
- 点击某个生字，自动填入“字或词语、参考拼音、来源”。
- 家长仍可手动修改参考拼音，多音字不强行自动判定。

验收标准：

- 能选择“一年级上 · 第一单元 · 第一课”这类来源。
- 保存后的字词能记录 `sourceId` 和 `sourceLabel`。
- 字词列表里能看到来源，后续统计可按课文/单元汇总。

### 6.3.2 按课本听写

目标：家长不用手动整理每课听写范围，直接按“小学语文 1-6 年级、上下册、单元、课文”选择本课生字和适合听写的课内/不超纲生词。

入口：

- 字词星球“添加”子页面里的“按课本添加”。
- 字词星球顶部可保留“课本听写”快捷入口，但不作为首页一级星球。
- 听写提醒页可以从“按课本选词”进入。

数据范围：

- 覆盖 1-6 年级，共 12 册。
- 每册按单元和课文组织。
- 每课拆分两类：
  - `newCharacters`：本课生字表。
  - `lessonWords`：课文中出现，或由本课/此前已学字组成的不超纲生词。

不超纲规则：

- 一年级词语只由一年级已学字或本课生字组成。
- 二年级及以上可以使用此前年级已学字，但不能提前引入后续年级才要求掌握的生字。
- 如果某个词语含未学字，需要标记 `withinGrade: false`，默认不进入听写候选。
- 正式发布包只使用 `verified: true` 的课文数据。

交互：

1. 选择年级。
2. 选择上册/下册。
3. 单独选择单元，页面只展示该单元的课文，不一次展示整册内容。
4. 选择课文范围：
   - 某一课：单选一篇课文。
   - 选择几课：同一单元内多选课文。
   - 整个单元：自动选择当前单元全部课文。
5. 页面展示当前范围摘要，例如“一年级上册 · 第一单元 · 第1课、第3课”。
6. 页面按所选范围汇总“课文生字”和“课内/不超纲生词”，重复字词自动去重。
7. 家长继续勾选具体字词后，可加入听写列表或保存到字词库。
8. 保存后每个字词保留原始书、单元、课文来源；跨多课出现时保留多个课文引用。

验收标准：

- 能从一年级到六年级切换课本范围。
- 切换年级或册别后，单元和课文选项同步刷新。
- 能选择单独一课、同单元多课或整个单元。
- 未选择课文时不能加入听写列表。
- 整单元选择不会把其他单元内容混入结果。
- 多课中重复出现的字词只展示一项，但可以查看全部来源课文。
- 一课内可以同时选择单字和词语。
- 词语超过一个字时，每个字均可独立选择“会 / 不会”。
- 未核对或未授权的数据不能混入正式内置包。

### 6.3.3 语音/图片智能录入

目标：减少家长手动输入，把老师发来的听写语音、作业照片、课本截图先识别成文本，再由家长选择真正要练的字词。

入口：

- 字词星球顶部提供“语音录入”和“图片录入”。
- 语音录入用于老师语音、家长口述、听写音频。
- 图片录入用于作业照片、练习册截图、课本生字页截图。

识别后流程：

1. 识别结果先进入“识别文本”页面，允许家长手动修改。
2. 如果语音或图片识别失败，不清空已识别内容，提供“继续录音、补拍一张、手动粘贴、重新识别”。
3. 系统按换行、标点、语义把长文本拆成多组，例如“今天听写”“课文词”“老师补充”。
4. 家长可以先处理某一组，也可以整组加入听写或忽略整组。
5. 进入某组后，系统按标点、空格、换行和常见中文词语切分，生成候选字词。
6. 默认优先展示多字词，提供“只看多字词”“只看未处理”“全选听写”“清空”。
7. 家长从候选里快速移除无关词，保留要加入字词库的内容。
8. 对超过 1 个字的词语，必须逐字选择“会 / 不会”。
9. 每个候选还要区分：
   - 不会写的字词。
   - 只是为了本次听写准备的词。
10. 保存后进入当前孩子字词库，并默认加入听写。

字段补充：

| 字段 | 必填 | 说明 |
|------|------|------|
| importType | 是 | `manual`、`speech`、`image` |
| rawText | 否 | 原始识别文本，便于回看和纠错 |
| selectedText | 是 | 家长确认后的字或词语 |
| groupTitle | 否 | 自动分组标题，如“今天听写”“课文词” |
| groupIndex | 否 | 分组序号 |
| unknownScope | 是 | 当前固定为 `chars`，所有词统一按字记录 |
| unknownChars | 否 | 记录不会字的原始下标和字符 |
| dictationOnly | 否 | true 表示只是听写准备词，不增加错误次数 |
| confidence | 否 | API 返回的识别置信度 |

验收标准：

- 语音或图片识别失败时，不影响手动新增。
- 语音或图片部分识别失败时，已识别文本不能丢失。
- 多组文本可以分组处理，支持整组加入听写或忽略整组。
- 识别结果必须经过家长确认，不自动批量入库。
- “时候”需要同时判断“时”和“候”，例如保存为“时=会、候=不会”。
- “游泳”这类词可以只标为听写准备词，不必标错字。
- 保存后的词语能继续匹配教材出处；匹配不到时来源标为“日常”。

### 6.3.4 后续智能录入边界

本期不做语音转文字和图片转文字，只保留后续入口与数据字段。任何识别结果都必须先由家长确认，再进入字词库或听写列表。

### 6.4 错字本

目标：把“错过的字”变成可复习、可统计、可导出的练习材料。

字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 内容 | 是 | 错字或词语 |
| 拼音 | 否 | 用于默写纸提示 |
| 错误次数 | 自动 | 首次加入为 1 |
| 最近错误时间 | 自动 | 每次再错更新 |
| 来源 | 否 | 例如“第 3 单元听写” |
| 状态 | 自动 | 待练、复习中、已掌握 |

新增规则：

- 从听写结果标记错字：如果错字不存在，新增并设错误次数为 1。
- 手动新增错字：同样错误次数为 1。
- 如果同一个孩子同一个内容再次写错，不新建重复项，只执行错误次数 +1，并更新最近错误时间。

核心操作：

- 又错一次：错误次数 +1。
- 标记已掌握：从待练列表移出，但保留历史。
- 恢复练习：已掌握后再次加入待练。

验收标准：

- 错误次数排序默认从高到低。
- 错字详情能看到错误次数和最近错误时间。
- 生成默写纸时可选择“只导出错字”“错字 + 生字”。

### 6.5 听写提醒

目标：提醒家长不要隔太久才复习。

提醒规则：

- 新增生字或错字后，默认 3 天未练习进入“该复习”。
- 错误次数 >= 3 的字，默认 1 天未练习进入“重点复习”。
- 已掌握的字默认不提醒，除非家长手动恢复。

首页展示：

- “3 个字该复习了”
- “2 个高频错字建议今天听写”
- 展示前 5 个字，更多进入听写页。

不做事项：

- 首版不接微信订阅消息。
- 首版不做后台定时通知。
- 首版只做打开小程序后的本地提醒。

验收标准：

- 每个孩子的提醒独立计算。
- 修改孩子后提醒数量立刻刷新。
- 听写完成后，相关字词的最近练习时间更新，提醒消失或降级。

### 6.5.1 听写播报

目标：播放听写列表中的完整词语，让家长不用一直盯着屏幕念词。

配置项：

| 配置 | 默认值 | 说明 |
|------|--------|------|
| 词语间隔 | 8 秒 | 每个词播完后等待多久 |
| 重复次数 | 2 遍 | 同一个词连续播几次 |
| 语速 | 慢速 | 低年级默认慢速 |

播报规则：

- 播放前必须先进入听写列表确认内容。
- 只播报要听写的词语，不播答案解释。
- 可以先试听单个词。
- 播报过程中可以暂停、继续、跳到下一个词。
- 播报完成后进入“记录结果”。

验收标准：

- 选择 5 个词时，可以按设置自动顺序播报。
- 修改间隔后，下一次播报立即生效。
- 播放不可用时，听写列表仍可查看和修改，家长可以手动读词。

### 6.5.2 听写列表与批改

目标：让课本、错词和字词库选择都进入同一个可编辑列表，再完成“播放、批改、错字沉淀”闭环。

加入听写列表：

| 选词位置 | 加入规则 |
|----------|----------|
| 错词和听写提醒 | 把不会字关联的完整词加入列表 |
| 课本听写 | 按年级、册别、单元和课文勾选后加入列表 |
| 字词库 | 勾选已有完整词语后加入列表 |
| 手动添加 | 保存新词后可加入列表 |

列表操作：

- 新增：继续从课本、字词库或手动添加词语。
- 删除：只从本次听写列表移除，不删除字词库原记录。
- 编辑：修改本次听写副本的词语或拼音，不覆盖字词库原记录。
- 去重：同一 `wordId` 只保留一项；没有 `wordId` 时按规范化后的完整词语去重。
- 顺序：默认按加入顺序播放，后续可增加拖动排序。
- 约束：列表至少保留 1 个词才能开始听写。

统一流程：

```text
从课本/错词/字词库选择
  ↓
加入统一听写列表
  ↓
增删改并确认顺序
  ↓
按间隔和重复次数播报
  ↓
播报完成
  ↓
逐词选择“正确 / 错误”
  ↓
错误词必须继续选择具体写错的字
  ↓
保存批改结果
  ↓
更新词语统计、不会字统计和复习时间
  ↓
可只重听本次错词
```

批改规则：

1. 批改对象首先是完整词语，每个词必须选择“正确”或“错误”。
2. 选择“错误”后，必须点选一个或多个具体错字，未选择时不能保存。
3. 整词正确时，词语的听写次数和正确次数 +1。
4. 整词错误时，词语的听写次数和错误次数 +1。
5. 被点选的具体错字已存在时，错误次数 +1，并更新最近错误时间。
6. 被点选的具体错字不存在时，自动新增不会字，错误次数初始为 1，并与当前完整词建立关联。
7. 整词正确时，该词已关联的不会字正确次数 +1，并更新最近正确时间。
8. 整词错误但只错部分字时，该词已关联且本次未被点选的不会字正确次数 +1；普通字写对不自动创建记录。
9. 保存成功后，本次听写进入“已批改”状态，同一记录不能重复结算。
10. 允许修改未保存的批改选择；已保存结果如需修改，应执行“撤销上次结算后重新保存”，不能直接再次累加。

结果页展示：

- 本次正确词数、错误词数和正确率。
- 已有错字的正确/错误次数变化。
- 本次新加入的错字。
- “只听写本次错词”“返回字词星球”操作。

验收标准：

- 课本、错词和字词库选择都能加入同一个听写列表。
- 在列表删除词语不会删除字词库或教材数据。
- 编辑列表项只修改本次听写副本。
- 列表中重复选择同一词时不产生重复项。
- 所有词完成批改且所有错误词已选择具体错字后，保存按钮才可用。
- “时候”标记错误并只选择“候”时，只增加“候”的错误次数，不增加“时”的错误次数。
- 原本没有“泳”的孩子，将“游泳”标错并选择“泳”后，自动新增“泳”并关联“游泳”。
- 已有关联错字“慢”的“慢慢”整词写对后，“慢”的正确次数 +1。
- 同一听写记录重复点击保存，不得重复增加任何统计。

### 6.6 生成 A4 默写纸

目标：用拼音和字词生成适合保存、打印、手写的默写练习纸。

输入：

- 选择孩子。
- 选择范围：生字、错字、重点错字、本周新增、自定义勾选。
- 是否显示拼音。
- 是否显示字格。
- 每页字数：12、16、20、24。

输出：

- 图片：适合直接保存到相册或微信转发。
- Word：适合家长二次编辑。
- PDF：适合打印。

A4 排版要求：

- 纸张比例按 A4 竖版：210mm x 297mm。
- 上方包含标题、孩子昵称、日期。
- 每个字词占一个稳定练习块。
- 拼音在上，默写格在下。
- 每行 2 或 3 个练习块，手机预览时按比例缩放。
- 留出打印边距，避免内容贴边。
- 字格和下划线要清晰，不能太浅。

验收标准：

- 生成 12、16、20、24 个字时，页面都不溢出。
- 长词超过 4 个字时自动使用横向练习块，避免挤压。
- 图片导出清晰度不低于 1240 x 1754。
- Word/PDF 导出失败时，至少能退化保存图片。

## 7. 非功能需求

数据：

- 所有数据保存在微信小程序本地缓存。
- 数据结构需带版本号，方便后续迁移。
- 需要提供“导出本地数据”和“清空当前孩子数据”的能力。

体验：

- 首页切换孩子后 300ms 内完成刷新。
- 生字/错字新增流程不超过 2 个页面。
- 每个主操作按钮文案必须是动作，不使用抽象术语。

兼容：

- 微信小程序基础库不低于现有项目要求。
- iPhone 小屏、iPad 微信、安卓主流机型都要检查 A4 预览缩放。
