# 学习星球 · 电子宠物模块 V1 产品需求文档

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 模块名称 | 宠物星球 |
| 版本 | V1 产品方案 |
| 面向用户 | 5-12 岁儿童及家长 |
| 依赖模块 | 音标、拼音、字词听写、多孩子本地档案 |
| 核心闭环 | 完成学习 -> 获得经验和星星积分 -> 照顾/装扮宠物 -> 宠物成长 -> 继续学习 |
| 数据边界 | 默认本地保存，不做账号、排行、社交和付费 |
| 交互原型 | `prototypes/electronic-pet-v1/index.html` |

## 2. 背景与问题

当前学习星球已有音标、拼音和字词听写能力，但各模块主要依赖“完成进度”驱动。孩子完成一关后，奖励只停留在数字变化，缺少持续、可见、带感情的反馈。

电子宠物不是独立小游戏，而是覆盖所有学习模块的长期奖励层：

```text
学习任务
  -> 即时奖励：经验、星星积分、宠物反应
  -> 短期目标：喂养、玩耍、完成今日照顾
  -> 中期目标：升级、解锁动作和配饰
  -> 长期目标：收集装扮、成长相册
```

需要解决的问题：

1. 孩子为什么愿意第二天继续回来。
2. 音标、拼音、听写三个模块如何共享同一套奖励。
3. 积分如何有用途，但又不让照顾宠物挤占学习。
4. 宠物如何表达需要陪伴，而不制造“宠物会饿死”的负担。
5. 多个孩子共用设备时，宠物和资产如何完全隔离。

## 3. 产品目标与非目标

### 3.1 V1 目标

- 每个孩子可领养一只独立宠物并命名。
- 完成音标、拼音、听写任务后获得经验和星星积分。
- 宠物可升级，等级变化有明确外观或动作反馈。
- 星星积分可用于喂养、玩耍和购买配饰。
- 配饰购买后永久拥有，可自由穿戴和卸下。
- 首页能看到宠物状态、今日任务和最近可达成目标。
- 家长能看到奖励来源，避免孩子误解为充值货币。

### 3.2 成功指标

首版只做本地匿名统计口径设计，不强制接服务端：

| 指标 | 观察目标 |
|---|---|
| 宠物领养完成率 | 进入宠物星球的孩子中，80% 完成领养 |
| 学习后领取奖励率 | 80% 以上完成任务后看到并领取奖励 |
| 次日回访率变化 | 相比无宠物版本有提升 |
| 每周跨模块学习率 | 孩子一周内使用 2 个及以上学习模块 |
| 积分使用率 | 获得积分的孩子中，70% 至少完成一次喂养/玩耍/购买 |

### 3.3 V1 不做

- 宠物死亡、生病、逃走、降级。
- 连续登录中断惩罚。
- 好友、拜访、排行榜、交易、赠送。
- 充值、广告换积分、抽卡、概率宝箱。
- 同一孩子同时养多只宠物。
- AI 自由聊天和开放式语音对话。
- 复杂小游戏；V1 玩耍使用短动画和选择反馈。
- 根据真实时间持续扣减到极低状态。

## 4. 产品原则

### 4.1 学习优先

- 主要积分必须来自有效学习任务。
- 重复点击喂养、玩耍不能生成更多积分。
- 宠物反馈用于强化学习，不用恐吓、催促或贬低孩子。

### 4.2 三套数值分离

| 数值 | 用途 | 是否消费 | 是否下降 |
|---|---|---|---|
| 经验值 XP | 升级、解锁内容 | 否 | 否 |
| 星星积分 | 喂养、玩耍、购买配饰 | 是 | 消费时下降 |
| 状态值 | 饱腹、心情、活力 | 否 | 每日温和重置或互动时变化 |

经验值和星星积分不能混为一个字段。否则购买配饰会导致等级倒退，孩子也无法理解。

### 4.3 无焦虑照顾

- 状态最低只显示“想吃点东西”“想和你玩”，不显示危险、疾病或倒计时。
- 24 小时未进入时，状态只回到建议值，不继续无限下降。
- 长时间未使用后回来，宠物说“你回来啦”，不说“你怎么才来”。
- 所有关键学习功能不因宠物状态不足而锁定。

### 4.4 本地与分孩子

- 每个孩子独立保存宠物、经验、积分、库存、穿戴和奖励记录。
- 切换孩子后，宠物数据立即同步切换。
- 清理微信缓存会丢失数据，需要延续现有本地数据提示。

## 5. 核心概念

### 5.1 宠物

V1 推荐只制作一个主宠物种族“星芽兽”，通过颜色、名字和配饰形成个性。原因：

- 降低首版美术和动画成本。
- 保证所有配饰在同一骨架和锚点上稳定显示。
- 避免三只宠物造成三倍动作、低状态和穿戴资产。

领养时可选择三种初始色：

- 晴空蓝：安静、好奇。
- 薄荷绿：活泼、爱探索。
- 暖橙黄：热情、喜欢鼓励。

三种颜色只改变主色，不改变技能、奖励和升级速度。

### 5.2 经验值

经验值表示孩子和宠物一起成长的累计成果：

- 永久累计。
- 不可购买。
- 不可消费。
- 不因答错、忘记学习或长期未登录而扣除。

### 5.3 星星积分

星星积分是内部免费奖励货币：

- 由学习任务、首日照顾引导和等级奖励产生。
- 用于食物、玩耍和配饰。
- 不提供人民币购买入口。
- 所有收入和支出写入本地流水，便于排查重复发奖。

### 5.4 状态值

| 状态 | 范围 | 作用 |
|---|---|---|
| 饱腹 | 0-100 | 影响待机表情和喂养反馈 |
| 心情 | 0-100 | 影响互动动作和问候语 |
| 活力 | 0-100 | 影响宠物动作节奏，不限制学习 |

展示档位：

- 70-100：状态很好。
- 40-69：普通。
- 0-39：需要陪伴。

## 6. 用户旅程

### 6.1 首次领养

```text
首页点击宠物星球
  -> 说明“学习可以让宠物成长”
  -> 选择初始色
  -> 输入昵称（默认“芽芽”）
  -> 确认领养
  -> 获得新手礼包 30 星星积分
  -> 进入宠物小屋并完成一次免费喂养
```

规则：

- 名称 1-8 个中文、英文、数字。
- 不允许空白、换行和纯符号。
- 可使用默认名直接继续。
- 每个孩子只走一次领养流程。
- 家长设置中可改名，不允许重置领养来重复拿礼包。

### 6.2 日常学习

```text
进入学习模块
  -> 完成有效任务
  -> 结算弹层展示 XP + 星星积分
  -> 宠物做庆祝动作
  -> 奖励自动入账
  -> 返回首页时今日任务同步更新
```

“自动入账”比“点击领取”更稳妥，避免孩子关闭页面后丢奖励。按钮文案使用“去看看宠物”，不是发奖必要步骤。

### 6.3 照顾和装扮

```text
宠物小屋
  ├─ 喂养：选择已拥有食物或直接使用基础食物
  ├─ 玩耍：选择球、积木、泡泡棒等互动
  ├─ 装扮：查看已拥有配饰并穿戴
  ├─ 商店：用星星积分购买物品
  └─ 成长：查看等级、解锁和学习纪念
```

## 8. 功能需求

### 8.1 学习星球首页入口

展示：

- 宠物缩略形象。
- 宠物名称和等级。
- 当前星星积分。
- 一句状态，如“芽芽今天想陪你学 1 关”。
- 有新等级或新配饰时显示红点，不使用连续闪烁。

未领养状态：

- 显示“领养一位学习伙伴”。
- 点击进入领养页。

验收：

- 切换孩子后入口内容随孩子变化。
- 没有孩子档案时沿用现有添加孩子引导。

### 8.2 领养页

页面内容：

- 三种初始颜色预览。
- 宠物特点说明只描述性格，不暗示能力差异。
- 名称输入。
- 隐私和本地存储说明。

确认后：

- 创建宠物档案。
- 发放 30 星星积分。
- 写入唯一事件 `pet_adopted`，保证不可重复发奖。
- 进入新手喂养引导，首次基础食物免费。

### 8.3 宠物小屋

顶部：

- 返回学习星球。
- 当前孩子。
- 星星积分余额。

核心区域：

- 宠物大图。
- 当前穿戴配饰。
- 等级和经验进度。
- 点击宠物触发 1 次短反应；连续点击不产生奖励。

状态区：

- 饱腹、心情、活力三个状态。
- 使用图标、颜色和短文案，不只依赖颜色。

快捷操作：

- 喂养。
- 玩耍。
- 装扮。
- 商店。

今日任务：

- 最多显示 3 项。
- 优先展示离完成最近的任务。
- 点击任务跳转到对应学习模块。

最近目标：

- 示例：“再获得 40 XP 升到 4 级，解锁星星发卡。”

### 8.4 学习奖励

#### 8.4.1 发奖原则

- 只有完成一个可判定的学习结果才发奖。
- 同一关首次通过奖励最高，重复练习给少量练习奖励。
- 失败不扣分、不扣经验，可给 1 次“认真尝试”经验，但每日有上限。
- 所有奖励必须带 `eventId`，重复结算不能重复入账。

#### 8.4.2 基础奖励表

| 行为 | XP | 星星积分 | 每日规则 |
|---|---:|---:|---|
| 音标关卡首次通过 | 12 | 8 | 每关仅首次奖励 |
| 音标已通过关卡复习完成 | 4 | 2 | 每关每天 1 次，最多 3 关 |
| 拼音关卡首次通过 | 12 | 8 | 每关仅首次奖励 |
| 拼音已通过关卡复习完成 | 4 | 2 | 每关每天 1 次，最多 3 关 |
| 自由拼读完成 5 个有效组合 | 8 | 5 | 每天 1 次 |
| 听写完成 1-4 个词 | 6 | 4 | 每天最多 2 组 |
| 听写完成 5-9 个词 | 10 | 7 | 每天最多 2 组 |
| 听写完成 10 个及以上 | 14 | 10 | 每天最多 2 组 |
| 完成错字复习并标记结果 | 6 | 4 | 每天最多 2 组 |
| 今日首次完成任意学习 | 5 | 5 | 每天 1 次 |
| 今日完成两个不同模块 | 10 | 8 | 每天 1 次 |
| 认真尝试但未通过 | 2 | 0 | 每天最多 3 次 |

每日建议收入：

- 普通学习日：25-45 XP，18-30 星星积分。
- 完成较多任务：50-75 XP，35-50 星星积分。
- V1 星星积分每日奖励硬上限：60，首通一次性奖励不计入上限。

#### 8.4.3 听写结果边界

当前听写模块未必有自动判分，因此：

- 完成播报队列即可获得“完成听写”基础奖励。
- 家长记录结果后，再发放“完成复盘”奖励。
- 不能按孩子自报全对发额外大量积分，避免诱导虚报。

### 8.5 今日任务

每日生成 3 项，至少包含一个可快速完成任务：

| 任务示例 | 奖励 |
|---|---|
| 完成 1 个音标或拼音关卡 | 5 XP + 5 积分 |
| 完成 5 个字词听写 | 5 XP + 5 积分 |
| 复习 1 个已学关卡 | 3 XP + 3 积分 |
| 完成两个不同学习模块 | 10 XP + 8 积分 |
| 给宠物喂一次基础食物 | 不额外发积分，增加状态 |

规则：

- 每天本地日期第一次进入时生成。
- 根据可用模块生成，不给尚未开放的任务。
- 任务未完成不惩罚，不累积“欠任务”。
- 修改设备时间可能影响日期，使用奖励事件去重和日期快照降低重复领取。

### 8.6 经验与升级

#### 8.6.1 等级曲线

V1 开放 1-20 级。升级所需累计 XP：

| 等级 | 累计 XP | 预计节奏 |
|---:|---:|---|
| 1 | 0 | 领养 |
| 2 | 40 | 第 1-2 天 |
| 3 | 100 | 第 3-4 天 |
| 4 | 180 | 第 1 周 |
| 5 | 280 | 第 2 周 |
| 6 | 400 |  |
| 7 | 550 |  |
| 8 | 730 |  |
| 9 | 940 |  |
| 10 | 1180 | 约 4-6 周 |
| 11-20 | 前一级需求逐步增加 270-500 XP | 长期目标 |

建议公式仅用于构建配置，不在运行时猜测：

```text
level 1-10：使用人工配置表
level 11-20：继续使用审核后的静态配置
```

#### 8.6.2 升级奖励

- 每级：10-25 星星积分。
- 2 级：解锁玩耍。
- 3 级：解锁装扮间。
- 4 级：解锁第一件等级限定配饰。
- 5 级：宠物成长阶段从“幼芽”变为“小星苗”。
- 8 级：解锁新待机动作。
- 10 级：解锁成长纪念背景。
- 15、20 级：后续阶段外观变化。

升级后自动保存，庆祝动画只播放一次；中途退出后再次进入显示简化提示，不重复发奖励。

### 8.7 喂养

基础食物：

| 物品 | 价格 | 效果 |
|---|---:|---|
| 星星饼干 | 8 积分 | 饱腹 +20 |
| 云朵牛奶 | 12 积分 | 饱腹 +15，活力 +5 |
| 彩虹果杯 | 18 积分 | 饱腹 +25，心情 +5 |

规则：

- 饱腹大于等于 90 时提示“已经吃得很饱啦”，不消费。
- 每天第一次基础喂养价格为 0，仅限星星饼干。
- 食物在商店购买后进入背包；也可在喂养弹层直接购买并使用。
- 喂养增加状态，不直接增加 XP 或积分。

### 8.8 玩耍

| 玩具 | 获取方式 | 效果 |
|---|---|---|
| 弹弹球 | 默认拥有 | 心情 +15，活力 -5 |
| 拼图积木 | 30 积分永久购买 | 心情 +12，活力 -3 |
| 泡泡棒 | 50 积分永久购买 | 心情 +20，活力 -8 |

规则：

- 玩具永久拥有，不是一次性消耗。
- 单次互动 3-8 秒，避免变成长时间小游戏。
- 活力低于 10 时仍可互动，但宠物提示先休息；V1 不单独售卖休息资源。
- 玩耍不产出积分，避免形成自循环刷币。

### 8.9 装扮与穿戴

装备槽：

- `head`：帽子、发卡、耳机。
- `neck`：围巾、领结、奖牌。
- `back`：小书包、披风。
- `hand`：小旗、魔法笔；同一动作可能隐藏手持物。
- `room`：小屋背景主题。

规则：

- 每个槽位最多穿戴 1 件。
- 配饰永久拥有，可随时卸下。
- 商店预览不改变真实穿戴，点击确认后保存。
- 已拥有物品显示“穿戴”，不再显示价格。
- 等级限定物品达到等级后才可购买；未达到时展示具体条件。
- 不使用随机抽取。

价格建议：

| 类型 | 价格区间 |
|---|---:|
| 基础头饰 | 60-100 |
| 基础颈饰 | 80-120 |
| 背部配饰 | 120-180 |
| 稀有配饰 | 200-350 |
| 房间背景 | 300-600 |

### 8.10 成长手册

展示：

- 当前等级、累计 XP、下一级奖励。
- 宠物领养日期。
- 学习纪念：完成第 1 个音标、第 10 个拼音、第一次 10 词听写等。
- 已解锁动作和装扮数量。

不展示：

- 与其他孩子比较。
- “落后”“失败次数”排行榜。
- 连续学习断签天数。

## 9. 状态变化规则

建议使用“每日温和回落”，而不是按分钟实时扣减：

```text
跨过一个本地自然日：
饱腹 = max(35, 饱腹 - 20)
心情 = max(40, 心情 - 10)
活力 = min(100, 活力 + 20)
```

说明：

- 最多按一次日切处理，即使 10 天未打开也不连扣 10 次。
- 喂养降低活力的设计不必要，保持简单。
- 完成任意学习后，宠物心情额外 +3，每天最多 +9。
- 升级时三项状态恢复到至少 80。

## 11. 边界与异常

| 场景 | 处理 |
|---|---|
| 奖励结算页重复打开 | 根据 `eventId` 返回已入账结果，不重复增加 |
| 积分不足 | 显示还差多少，并提供“去完成任务”入口 |
| 达到状态上限 | 不消费物品 |
| 删除孩子 | 同时删除该孩子宠物数据，二次确认说明不可恢复 |
| 切换孩子 | 清理页面临时预览，重新读取目标孩子宠物 |
| 设备时间回拨 | 当天任务不重新生成；奖励流水继续按事件去重 |
| 缓存空间不足 | 保留核心数值和库存，成长日志限制最近 200 条 |
| 配饰资源缺失 | 自动回退为不穿戴，不阻塞进入宠物小屋 |
| 未开放拼音模块 | 今日任务不生成拼音任务 |

## 12. 家长说明

在任务中心提供“奖励规则”：

```text
星星积分只由学习和成长任务获得，不能充值，也不会影响正常学习功能。
经验值只会增加，不会因为买东西或几天没学习而减少。
宠物不会生病或离开，孩子可以按自己的节奏学习。
```

## 14. 版本规划

### V1：最小成长闭环

- 1 个宠物种族、3 个初始色。
- 1-10 级完整可玩，数据支持 20 级。
- 音标、拼音、听写奖励接入。
- 喂养、玩耍、装扮、商店、成长手册。
- 12-16 件配饰，3 种食物，3 个玩具，2 个房间背景。

### V1.1：内容补充

- 等级扩到 20 级。
- 新动作、成长纪念和节日免费配饰。
- 家长可调整每日任务数量，不调整单项奖励数值。

### V2：跨端与恢复

- 在账号和隐私方案明确后考虑云同步。
- 多宠物收藏，但同一时间只展示一只主宠物。
- 轻量场景探索，不做付费或概率系统。

## 15. 验收标准

### 数据

- 每个孩子拥有独立宠物、XP、积分、状态、库存和穿戴。
- 所有发奖操作可重复调用但只入账一次。
- XP 消费路径不存在。
- 积分不足时任何购买都不会产生负余额。

### 学习联动

- 音标首次过关、复习过关能发放不同奖励。
- 拼音奖励使用独立学习项 ID，不与音标冲突。
- 听写根据完成数量分档发奖。
- 未领养宠物时奖励先进入孩子的钱包，领养后可见，不强迫先养宠物。

### 宠物互动

- 饱腹大于等于 90 时不能误消费食物。
- 玩耍不产生积分和 XP。
- 配饰购买后永久拥有，卸下后不会丢失。
- 升级、解锁和奖励中途退出后不会重复触发。

### 儿童体验

- 不出现死亡、生病、逃走、惩罚或羞辱文案。
- 不出现充值、广告、抽卡和排行入口。
- 关键按钮触控区域不小于 44 x 44 px。
- 状态变化同时有文字或图标说明，不只使用红绿颜色。
