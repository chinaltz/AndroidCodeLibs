# 心愿存折 · 积分模块 V2 原型方案

> 依据用户提供的「心愿存折」封面 +「荣誉记录本」内页实物，在现有 `points-module-*` 文档与配置之上，重构 UI 与产品形态。  
> 配套：`points-module-product-requirements.md` · `points-module-technical-design.md` · `config/points-*`

---

## 2. 产品定位（重构后）

| 维度 | V1 原方案 | V2 存折方案 |
|---|---|---|
| 模块名 | 积分星球 | **心愿存折**（副标题：激励孩子养成好习惯） |
| 核心隐喻 | 数字积分板 | **银行存折 + 荣誉记录本** |
| 孩子视角 | 余额 + 积分墙 | **开户档案 → 印章页 → 心愿兑换** |
| 家长视角 | 规则管理 | **开户设置 + 记一笔 + 规则编辑** |
| 标记形式 | 4 种 emoji 图标 | **4 种标记 + 存折 UI 皮肤** |

产品闭环不变：

```text
家长配置加分项 / 减分项 / 日上限 / 标记样式
  -> 日常「记一笔」（盖章 / 贴花 / 贴星）
  -> 孩子看存折内页：28 格印章墙 + 心愿进度
  -> 攒够奖章兑换心愿 / 周月学期目标
```

## 3. 实物 → 数字页面对照

### 3.1 封面（图 1 · 心愿存折）

| 实物元素 | 数字实现 | 页面 |
|---|---|---|
| 大标题「心愿存折」 | 可替换为 `{孩子昵称}的心愿存折` | 封面 / 首页首屏 |
| 副标题「激励孩子养成好习惯」 | 固定 slogan | 同上 |
| 粉紫渐变 + 波点 + 彩虹底 | 设计 Token（§6） | 全局背景 |
| 独角兽 / 气球 / 星星装饰 | 静态插画层（可随主题换） | 封面装饰 |
| — | 点击进入「翻开存折」 | 主 CTA：「打开我的存折」 |

**交互**：封面作为 `points-home` 首屏；上滑或点按钮进入内页（印章墙）。

### 3.2 开户页（图 2 · 上页）

| 实物字段 | 数字字段 | 来源 |
|---|---|---|
| 照片 | 孩子头像 | 已有 `children` 档案 |
| 编号 | 存折编号（自动生成 `PB-{childId 后 6 位}`） | 新建 |
| 姓名 | 昵称 | `child.nickname` |
| 性别 | 性别 / 头像类型 | `child.avatar` |
| 出生日期 | 可选 | `child.birthday`（扩展） |
| 兴趣爱好 | 可选文本 | `points.profile.hobbies` |
| 开户日期 | 首次 onboard 日期 | `points.profile.openedAt` |
| 开户单位 | 默认「家庭」可改 | `points.profile.issuer` |
| 注意事项 | 固定 2 条 + 链接「使用说明」 | `points-help` |
| 开户人签名 | 孩子昵称 + 卡通手印图标 | 展示态 |

**交互**：首次 onboard 步骤 1；之后可在「存折设置」查看，孩子只读。

### 3.3 印章墙（图 2 · 下页）

| 实物元素 | 数字实现 |
|---|---|
| 4 行 × 7 列 = **28 个圆格** | `tokenWall` 可视区固定 28 格；每格 1 个标记 |
| 圆格间蝴蝶结装饰 | CSS 背景图案 |
| 已贴标记 | 按 `tokenStyle` 渲染 flower / stamp / star / heart |
| 空格 | 虚线圆 + 浅粉底 |
| 「我的心愿」 | `goals.wish.text`（单行，≤20 字） |
| 「需要 __ 个奖章兑换」 | `goals.wish.targetMedals` 或关联活跃周/月目标 |

**规则**：

- 余额 `wallet.balance` = 已贴标记总数（与格数一致）。
- 最近 28 次**正向获得**填充格子；减分**不撕掉**已贴标记，只扣余额并记流水（保护成就感）。
- 满 28 格后：向左滚动归档或进入「下一页」（V1.1）；V1 显示「本页已满，继续攒入总余额」。

### 3.4 记一笔（家长快捷操作）

实物中没有对应页，用**半透明盖章板**覆盖在印章墙上方：

- 加分 Tab：网格展示所有启用 **加分项**（名称 + 分值 + 标记预览）。
- 减分 Tab：网格展示 **减分项**；默认二次确认。
- 点击加分项 → **盖章动画**（0.5s）→ 标记飞入下一个空格 → Toast「+2 按时完成作业」。

## 5. 标记与皮肤体系

### 5.1 标记样式（tokenStyle · 四选一）

与现有技术标准一致，存储枚举 `flower | stamp | star | heart`：

| ID | 名称 | 视觉 | 实物对应 | 推荐场景 |
|---|---|---|---|---|
| `flower` | 小红花 | 手绘五瓣红花 | 老师发小红花 | 低年级默认 |
| `stamp` | 小印章 | 圆形「棒」字章 | 荣誉记录本盖章 | 打卡契约感 |
| `star` | 小星星 | 黄色五角星 | 封面星星装饰 | 学习成就 |
| `heart` | 小心心 | 粉色爱心 | 品德关怀 | 亲子互动 |

渲染规范：

- 统一走 `points-token` 组件，禁止页面散落 emoji。
- 盖章动画：stamp 样式用「压下弹起」；flower 用「绽放」；star 用「闪烁」；heart 用「弹出」。

### 5.2 存折皮肤（bookSkin · V2 新增，可选）

| ID | 名称 | 说明 |
|---|---|---|
| `wish_pink` | 心愿粉（默认） | 对标实物封面 + 内页 |
| `honor_rose` | 荣誉玫瑰 | 略深粉，偏「荣誉记录本」 |
| `mint_fresh` | 清新薄荷 | 低幼备选 |
| `star_night` | 星空蓝 | 高年级备选 |

皮肤只改背景、边框、装饰插画；**不改变** `tokenStyle` 与余额逻辑。

### 5.3 减分视觉

- 不在 28 格上显示「黑印」。
- 流水页减分行用橙色 `-` 前缀；今日摘要单独显示「今日已扣 X」。
- 可选 V1.1：减分后格子上方短暂显示灰色虚线圈（不持久）。

## 7. 自定义加分项 / 减分项（能力确认）

沿用现有数据模型，UI 在 `points-rules-edit`：

### 7.1 加分项字段

| 字段 | 约束 | UI 控件 |
|---|---|---|
| 名称 | 1~12 字，必填 | 单行输入 |
| 分值 | 1~10 整数 | 步进器 |
| 每日次数上限 | 1~5 或空 | 步进器 + 「不限」开关 |
| 说明 | ≤40 字 | 多行输入 |
| 启用 | 布尔 | 开关 |
| 自动触发 | V2 预留 | 禁用 |

### 7.2 减分项字段

同上，分值为正整数，展示为 `-N`。

### 7.3 模板一键导入

| 模板 | 加分 | 减分 |
|---|---:|---:|
| `primary_daily` | 14 | 5 |
| `minimal` | 3 | 2 |
| `learning_focus` | 10 | 3 |

导入策略：onboard 可选；规则页「从模板恢复」需二次确认（覆盖当前规则）。

### 7.4 规则健康度（保留）

日上限默认 12；理论最大约 18 → 显示「略宽松，由日上限截断」。

## 9. 核心交互与动效

| 场景 | 动效 | 时长 |
|---|---|---|
| 加分成功 | 标记从按钮位置飞入下一空格 + 轻震动 | 500ms |
| stamp 样式 | 印章压下缩放 0.9→1.05→1 | 400ms |
| 日上限已满 | 格子上方浮层「今日已满，明天再来」 | — |
| 目标达成 | 全屏撒花 + 封面独角兽跳跃 | 1.2s |
| 切换标记样式 | 格内图标渐变替换，数值不变 | 300ms |
| 翻开存折 | 封面 3D 翻页过渡（CSS transform） | 600ms |
