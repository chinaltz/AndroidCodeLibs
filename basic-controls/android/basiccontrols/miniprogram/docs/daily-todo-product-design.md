## 模块拆分

| 模块 | 页面 | 存储 Key | 首页入口 |
|------|------|----------|----------|
| 每日任务 | `/pages/daily-todo/index` | `daily_todo_state_v1` | 打卡清单 · 拖拽排序 |
| 番茄钟 | `/pages/pomodoro/index` | `pomodoro_state_v1` | 专注计时 · 到点提醒 |

两个模块独立入口、独立存储；番茄钟首次打开会自动迁移旧版合并在 `daily_todo_state_v1` 里的计时数据。

## 1. 产品定位

### 每日任务

面向家长/孩子的**每日学习打卡清单**，还原实体「滑动打卡板」的使用习惯：

- 每天自动重置完成状态（滑块回到 ✗）
- 任务列表默认沿用**昨天**的配置（名称、顺序、预设时间）
- 支持拖拽排序、增删改、每条任务预设参考时长

### 番茄钟

独立**专注计时器**，还原电子计时器外观：

- 倒计时 / 正计时切换，默认 25 分钟番茄钟
- 彩虹花瓣进度环 + LED 数字表盘
- 到点震动 + 全屏闹钟 UI

| 角色 | 场景 | 期望 |
|------|------|------|
| 家长 | 每晚规划明天任务 | 添加/删除/排序/设预设时长 |
| 孩子 | 白天逐项完成 | 点击滑块切换 ✓ / ✗，一眼看进度 |
| 家长 | 番茄钟/收工提醒 | 设 59 分钟倒计时，到点弹闹钟 |

## 5. 核心规则

### 5.1 每日重置

| 事件 | 行为 |
|------|------|
| 首次打开 / 跨日 | 若 `daily.date !== 今天`，复制**昨天** items（无则 template），`done=false` |
| 手动「重置」 | 仅清零完成态，不改列表 |
| 增删改排序 | 同步写入 `template`，作为后续每天的默认源 |

### 5.2 计时器

| 模式 | 显示 | 到点 |
|------|------|------|
| 倒计时 | `preset - elapsed` | `elapsed >= preset` → 闹钟 |
| 正计时 | `elapsed` | 达到 preset 时闹钟（可选延长） |

- 预设 chip 点击 → 重置 elapsed，更新 preset
- 静音 → 仅关闭震动，弹层仍显示

### 5.3 拖拽排序

- 长按左侧 `≡` 手柄 → 拖动
- 松手 → `reorderItems(from, to)` 持久化

## 6. 数据模型

**Storage Key：** `daily_todo_state_v1`（按孩子 ID 分桶，与宠物模块一致）

```javascript
{
  children: {
    [childId]: {
      template: [
        { id, title, presetMinutes, sortOrder }
      ],
      daily: {
        date: '2026-06-08',
        items: [
          { id, title, presetMinutes, done, sortOrder }
        ]
      },
      timer: {
        mode: 'countdown' | 'countup',
        presetSeconds: 3540,
        elapsedSeconds: 0,
        running: false,
        alarmMuted: false,
        alarmActive: false,
        startedAt: 0
      }
    }
  }
}
```
