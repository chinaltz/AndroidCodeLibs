# 拼音星球 V1 · 产品需求文档

## 1. 产品定位

拼音星球是“学习星球”中的基础语文模块，面向幼小衔接和小学一年级儿童。

首版目标不是做完整语文课程，而是让孩子完成一条清晰闭环：

```text
认识拼音字母 -> 听标准示范音 -> 看口型/发音提示 -> 声韵拼读 -> 三题过关
```

产品沿用音标星球的低门槛交互：

- 地图上点一个拼音先试听。
- 点击“开始学习”进入单项学习。
- 学完进入三题过关。
- 每个孩子独立保存进度。
- 离线可用，不依赖在线 TTS。

## 2. 目标用户

### 2.1 核心用户

- 5-8 岁，正在接触汉语拼音的儿童。
- 需要陪练，但家长不确定发音是否标准的家庭。
- 已在学习星球中使用音标、字词模块的孩子。

### 2.2 核心痛点

1. 拼音表内容多，孩子不知道从哪里开始。
2. `b/p`、`d/t`、`n/l`、平翘舌等容易混淆。
3. 会背字母表，但不会把声母和韵母拼起来。
4. `j/q/x` 与 `ü`、整体认读音节等规则容易记混。
5. 家长需要一个可重复播放、可看进度的离线工具。

## 3. V1 内容范围

### 3.1 23 个声母

```text
b p m f
d t n l
g k h
j q x
zh ch sh r
z c s
y w
```

说明：产品按小学教学口径把 `y、w` 放入声母学习区；技术数据保留 `kind: initial`。

### 3.2 24 个韵母

| 分类 | 内容 |
|---|---|
| 单韵母 | a o e i u ü |
| 复韵母 | ai ei ui ao ou iu ie üe |
| 特殊韵母 | er |
| 前鼻韵母 | an en in un ün |
| 后鼻韵母 | ang eng ing ong |

### 3.3 16 个整体认读音节

```text
zhi chi shi ri
zi ci si
yi wu yu
ye yue yuan
yin yun ying
```

### 3.4 声调

- 一声：平。
- 二声：扬。
- 三声：拐弯。
- 四声：降。
- 轻声：首版在词语示例中出现，不单独作为闯关主关卡。

### 3.5 首版不做

- 汉字识字课程。
- 拼音输入法教学。
- 语音识别自动打分。
- 儿歌、动画课程和长视频。
- 复杂变调教学，例如“一、不”变调和连续三声。
- 方言纠音。

## 4. 学习路径

V1 建议拆成 8 个学习区域，避免一次展示 63 个卡片造成压力。

| 区域 | 内容 | 重点 |
|---|---|---|
| 1. 声调花园 | 四声 + a o e | 先听音高变化 |
| 2. 嘴唇小队 | i u ü + b p m f | 口型和送气 |
| 3. 舌尖车站 | d t n l | 舌尖位置 |
| 4. 舌根山谷 | g k h | 舌根发音 |
| 5. 微笑海湾 | j q x + ü | 去掉两点规则 |
| 6. 翘舌森林 | zh ch sh r | 平翘舌对比 |
| 7. 平舌沙地 | z c s | 送气和摩擦音 |
| 8. 拼读城堡 | 复韵母、鼻韵母、整体认读 | 声韵拼读 |

地图同时提供“按类别查看”，家长可以直接打开声母表、韵母表或整体认读表。

## 5. 页面与交互

### 5.1 拼音星球首页

展示：

- 当前孩子和总进度。
- 今日建议：继续上次学习、易混音专项。
- 8 个学习区域。
- 声母、韵母、整体认读三个快捷入口。
- “自由拼读”入口。

点击规则：

- 点击拼音卡片：立即播放示范音并选中。
- 点击底部主按钮：进入当前卡片学习页。
- 已完成卡片显示绿色完成态。
- 当前待学卡片显示黄色高亮态。

### 5.2 单项学习页

内容：

- 大号拼音字母。
- 发音示范音。
- 口型与发音提示。
- 易混对比，例如 `b/p`、`n/l`、`zh/z`。
- 2-3 个拼读示例。
- 声调切换。

主操作：

- “播放示范”。
- “慢速再听”。
- “去过关”。

### 5.3 自由拼读页

交互：

1. 左侧选择声母。
2. 右侧选择韵母。
3. 中间展示拼读过程，例如 `m + a -> ma`。
4. 切换四声，展示 `mā / má / mǎ / mà`。
5. 点击播放合成后的完整音节。

规则提示：

- 不合法组合置灰，不允许播放。
- `j/q/x + ü` 显示为 `ju/qu/xu`，同时提示“见到 j q x，ü 去掉两点”。
- 零声母韵母使用规范拼写，例如 `i -> yi`、`u -> wu`、`ü -> yu`。

### 5.4 三题过关

每个学习项默认三题：

1. 听音选字母。
2. 看字母选示例音节。
3. 跟读录音并自行对比。

拼读专项可替换为：

1. 听完整音节选择声母。
2. 根据声母和韵母拼出音节。
3. 选择正确声调。

V1 录音只支持“录制、回放、与标准音对比”，不提供自动评分。

### 5.5 家长进度

展示：

- 23 声母完成数。
- 24 韵母完成数。
- 16 整体认读完成数。
- 易混音错误次数。
- 最近 7 天练习记录。

## 6. 核心数据规则

### 6.1 独立孩子进度

- 拼音进度必须保存在当前孩子数据下。
- 不复用音标星球的 `doneIds`。
- 建议字段：`pinyinDoneIds`、`pinyinMistakes`、`pinyinLastUnitId`。

### 6.2 完成规则

- 三题过关全部完成后标记当前学习项已完成。
- 录音题只要求完成录制，不做机器评分。
- 同一关可重复练习，不重复增加完成数。

### 6.3 易混音

首版内置对比组：

```text
b / p
d / t
g / k
j / q / x
z / c / s
zh / ch / sh
z / zh
c / ch
s / sh
n / l
an / ang
en / eng
in / ing
```

答错时只记录练习项和错误次数，不给孩子展示负面排名。

## 7. 视觉与声音要求

- 复用学习星球现有蓝、薄荷绿、暖黄色视觉体系。
- 拼音星球主色建议为橙黄 + 天空蓝，和音标星球、字词星球区分。
- 字母必须使用清晰无装饰字体，`ɑ/a` 字形需要人工确认，不依赖系统字体偶然表现。
- `ü`、声调符号必须在 Android、iOS、小程序真机检查。
- 音频默认离线内置，第一次点击应立即播放。
- 所有示范音使用同一位普通话发音人或同一套音色。

## 8. 验收标准

### 8.1 内容

- 23 声母、24 韵母、16 整体认读音节数量完整。
- 每项都有名称音、发音提示、至少 2 个示例。
- 声调符号与数字声调映射正确。
- `j/q/x + ü`、零声母拼写规则有明确提示。

### 8.2 功能

- 点击任意拼音卡能播放正确音频。
- 退出后可恢复当前孩子的学习进度和上次位置。
- 切换孩子后拼音进度同步切换。
- 自由拼读只允许合法组合。
- 三题过关完成后地图状态立即更新。
- 离线状态下地图、学习、过关和音频可正常使用。

### 8.3 音频

- 正式包内每个音频都有来源、许可证或项目自录授权记录。
- 不使用云 TTS、系统 TTS 导出文件作为正式内置素材。
- 关键易混音由普通话教师或专业播音人员抽听。
- 音量、前后静音和文件规格统一。

## 9. 版本建议

### V1

- 地图、分类表、单项学习、自由拼读、三题过关。
- 离线音频。
- 本地多孩子进度。

### V1.1

- 易混音专项。
- 每周练习报告。
- 家长自定义练习列表。

### V2

- 经授权的真人发音全量替换。
- 本地或服务端语音识别评分。
- 拼音与字词星球联动，从生字反查拼音练习。
