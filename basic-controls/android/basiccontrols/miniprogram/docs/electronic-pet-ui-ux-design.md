# 学习星球 · 电子宠物模块 UI/UX 设计规格

## 1. 设计目标

宠物星球承担“学习结果可视化”的角色，不承担独立游戏主循环。

设计需要同时满足：

- 孩子一眼看懂宠物当前状态和下一步操作。
- 学习奖励比积分消费更突出。
- 家长能够理解积分来源、消费用途和无付费边界。
- 角色、背景、UI 图标使用统一的精品儿童 App 视觉语言。
- 页面可以先使用静态参考图，后续平滑替换成透明动画帧。

## 2. 视觉方向

### 2.1 关键词

```text
温暖、圆润、清晰、精致、低刺激、可收集、非幼稚化
```

不采用：

- 高饱和霓虹和整屏闪光。
- 写实毛发、真实动物器官。
- 大量金币、宝箱、抽卡转盘。
- 红色告警式饥饿提示。
- 复杂科幻面板和细小数值。

### 2.2 主色

| 语义 | 色值 | 使用 |
|---|---|---|
| 晴空蓝 | `#31A8FF` | 主按钮、XP、选中态 |
| 薄荷绿 | `#43CFC7` | 完成、拥有、良好状态 |
| 星星黄 | `#FFD166` | 星星积分、等级奖励 |
| 暖橙 | `#FF9D59` | 食物、提醒、短期目标 |
| 深蓝墨 | `#173A62` | 标题和主要描边 |
| 云白 | `#F9FDFF` | 卡片和安全留白 |
| 浅蓝底 | `#DDF4FF` | 页面背景 |

使用比例：

```text
云白/浅蓝底 65%
晴空蓝/薄荷绿 25%
星星黄/暖橙 10%
```

星星黄只用于奖励和解锁，避免整页黄色导致奖励失去层级。

### 2.3 形状和阴影

- 大卡片圆角：24-30 px。
- 小卡片圆角：16-20 px。
- 按钮圆角：16-18 px。
- 标签圆角：10-12 px。
- 主卡片使用 2 px 浅蓝边框。
- 阴影透明度控制在 8%-16%，不使用黑色硬阴影。
- 宠物和正式配饰使用统一深蓝描边。

## 3. 角色一致性规范

晴空蓝待机参考图是角色唯一母版：

```text
previews/pet_star_sprout_sky_idle_ref.png
```

所有动作必须锁定：

- 水滴形头身一体轮廓。
- 左侧普通嫩叶、右侧星形嫩叶。
- 两只深蓝椭圆眼和单点高光。
- 浅蓝腹部与星点分布。
- 短腿、鞋形脚掌、圆润四指手。
- 深蓝中粗描边和软胶渐变质感。

禁止动作图改变：

- 把整个头部变为星形。
- 把星形叶片改为普通叶片。
- 增加眼白比例或改成复杂动漫眼。
- 改变腹部形状、星点数量风格。
- 改变手指数量、脚掌结构或身体比例。

已修正庆祝动作参考：

```text

```

旧庆祝图只保留历史对照，不再作为生产参考。

## 4. 页面结构

### 4.1 领养页

目标：30 秒内完成选择，不引入能力比较。

视觉层级：

1. 角色参考图。
2. “学习伙伴”定位。
3. 三种配色。
4. 宠物昵称。
5. 领养按钮和 30 积分新手礼包说明。

交互：

- 切换配色时只替换角色颜色，不改变文案和能力。
- 默认选中晴空蓝。
- 昵称为空时使用“芽芽”。
- 点击确认后立即创建档案并发礼包。

### 4.2 宠物小屋

首屏从上到下：

```text
场景 + 宠物 + 一句话
等级与 XP
三项状态
喂养 / 玩耍 / 装扮 / 商店
今日任务
最近等级目标
```

场景要求：

- 宠物占首屏场景高度 48%-58%。
- 不让书架、窗户等背景元素压住角色脸和头顶嫩芽。
- 宠物脚底需要稳定视觉基线。
- 状态低时只换姿势和文案，不改变背景为灰暗或危险色。

### 4.3 学习奖励

目标：先强调“学会了什么”，再展示货币。

顺序：

1. 学习结果标题。
2. 宠物庆祝动作。
3. XP 和星星积分。
4. 首次通过/复习奖励说明。
5. 返回学习或去看宠物。

奖励自动入账，按钮不是领取开关。

动画节奏：

- 0-300 ms：结果卡淡入。
- 200-800 ms：宠物庆祝一次。
- 500-900 ms：XP、积分依次出现。
- 总时长不超过 1.2 秒。
- `prefers-reduced-motion` 或低性能设备使用静态图。

### 4.4 今日任务

- 固定最多 3 项。
- 已完成任务使用薄荷绿，不使用删除线。
- 奖励显示在右侧，单位固定为 `XP` 和星星图标。
- 任务卡点击后直达具体学习页面。
- 没完成不显示红点或倒计时。

### 4.5 装扮间

布局：

```text
上半屏：宠物实时预览
中部：头部 / 颈部 / 背部 / 手持 / 房间分类
下半屏：已拥有和未拥有物品
底部固定：保存穿戴
```

状态：

- 当前穿戴：蓝色描边 + “已穿戴”图标。
- 已拥有：白色卡片 + “穿戴”操作。
- 未拥有：展示价格和商店入口。
- 等级锁定：降低饱和度，同时显示具体等级。

预览和保存必须分离，误触返回时提示是否放弃未保存修改。

### 4.6 星星商店

- 食物明确标记“消耗品”。
- 玩具、配饰和房间明确标记“永久拥有”。
- 已拥有物品不再显示购买按钮。
- 余额不足时显示差额，不显示充值。
- 商品卡中不使用稀有度颜色、倒计时和限时促销。

### 4.7 成长手册

- 纵向时间线展示里程碑。
- 已解锁节点使用薄荷绿。
- 下一目标使用星星黄。
- 更远目标使用低对比浅蓝灰。
- 不展示失败次数、断签和同龄比较。

## 5. 核心状态矩阵

| 状态 | 角色动作 | 文案 | 可用操作 |
|---|---|---|---|
| 正常 | 待机 | 今天也一起学一小关吧 | 全部 |
| 饱腹偏低 | 期待、看向食物 | 想吃一点星星饼干 | 喂养突出 |
| 心情偏低 | 双手放身前 | 有空可以陪我玩一会儿 | 玩耍突出 |
| 活力偏低 | 半闭眼、轻微下沉 | 我想慢慢休息一下 | 学习仍可进入 |
| 学习完成 | 举手庆祝 | 我们又学会一点啦 | 查看奖励 |
| 升级 | 身体伸展、嫩芽张开 | 新等级解锁了新东西 | 查看解锁 |
| 久未进入 | 挥手欢迎 | 你回来啦，我一直在这里 | 不补罚、不追责 |

## 6. 弹层设计

### 喂养弹层

- 顶部显示当前饱腹值。
- 食物卡显示库存、效果和价格。
- 状态过满时禁用并说明原因。
- 使用后在原位置展示 `+20`，不弹连续多层弹窗。

### 玩耍弹层

- 玩具卡区分默认拥有和永久购买。
- 单次动画 3-8 秒。
- 中途退出不扣积分，因为玩具不是消耗品。

### 购买确认

仅对永久物品和价格大于等于 100 积分的商品二次确认。

文案：

```text
用 120 星星积分购买“小书包”？
购买后永久拥有。
```

## 7. 可访问性

- 主要触控区域至少 44 x 44 px。
- 正文最小 12 px，关键数值至少 14 px。
- 文字与背景对比度目标不低于 4.5:1。
- 完成/锁定/拥有不能只靠颜色表达。
- 动画可降级。
- 读屏标签使用“星星积分 94”，不只读“94”。

## 8. 响应式和安全区

- 设计基准：390 x 844 CSS px。
- 小程序基准：750 rpx。
- 首屏宠物场景最小高度 280 px。
- 底部固定按钮必须避开安全区。
- 小屏设备允许任务区下移，不压缩宠物到小于 180 px。
- 平板保持手机内容列宽 430-520 px，不横向铺满。

## 9. 原型与正式资产边界

当前原型：

- 领养页使用三色角色参考图。
- 奖励页使用统一骨架庆祝参考图。
- 小屋使用场景参考图。
- 装扮使用 CSS 分层占位验证槽位。

正式实现前必须完成：

- 透明背景角色主体。
- 同骨架动作帧。
- 配饰独立透明 PNG 和锚点验证。
- 场景裁切和小程序包体压缩。
- UI SVG 转 PNG 或确认目标平台 SVG 支持情况。

## 10. 评审通过条件

- 待机和所有动作保持同一角色骨架。
- 三色版本只改颜色。
- 宠物小屋首屏不拥挤。
- 学习奖励优先于积分消费。
- 装扮预览和真实保存分开。
- 余额不足没有充值暗示。
- 所有负面状态均无焦虑、无惩罚。
- 低端设备可关闭动画但不影响操作。
