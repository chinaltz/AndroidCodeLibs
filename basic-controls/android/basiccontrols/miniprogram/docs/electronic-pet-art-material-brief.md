# 学习星球 · 电子宠物形象与物料描述评审稿

## 1. 本阶段目标

本文件只定义形象和物料条件，用于确认方向。当前不生成图片。

评审通过后，再根据这里的描述制作：

- 宠物主形象。
- 状态和互动动作。
- 食物、玩具、配饰。
- 宠物小屋背景。
- 商店和状态 UI 图标。

## 2. 核心形象提案

### 2.1 名称

种族暂定：**星芽兽**

默认昵称：**芽芽**

命名理由：

- “星”连接学习星球的产品世界观。
- “芽”表达成长，不绑定猫、狗等现实动物。
- 方便后续做发芽、开花、星光等升级变化。
- 原创空间较大，降低与成熟商业 IP 过度相似的风险。

### 2.2 一句话形象

一只从学习星球种子中孵化出来的圆润小伙伴，头顶有一片星形嫩芽，短手短脚，像柔软的硅胶玩具；每完成一次学习，嫩芽会亮起一点温和星光。

### 2.3 正面外观描述

- 身体比例：头身约 1.35:1，整体接近圆角水滴形。
- 高度：完整站立形象中，身体占画布高度约 72%，四周留足动作空间。
- 头部：与身体自然连成一体，不画明显脖子。
- 头顶：两片嫩芽，其中一片轮廓带五角星的柔和暗示，但不能像硬质徽标。
- 眼睛：深蓝黑色椭圆眼，眼白很少；高光为单点，不做玻璃珠般复杂反射。
- 嘴：小号弧线嘴，可切换微笑、惊喜、困倦。
- 手脚：短而圆，手掌不画五根手指，脚掌像小靴形软垫。
- 腹部：浅色圆角区域，可在升级或获得奖励时显示微弱星点。
- 尾部：短小叶片尾巴，从正面只露少量，避免配饰遮挡复杂。
- 材质：哑光软胶或轻绒玩具感，边缘干净，没有真实毛发。
- 描边：深蓝灰或同色深一档，2D 方案使用中等粗细圆润描边。
- 阴影：仅允许身体内部硬边柔和明暗，不带地面投影。

### 2.4 三种初始颜色

#### 晴空蓝

- 主色：清亮天空蓝。
- 腹部：偏白浅蓝。
- 嫩芽：薄荷绿。
- 气质：安静、认真、好奇。

#### 薄荷绿

- 主色：浅薄荷绿。
- 腹部：暖白。
- 嫩芽：嫩黄色。
- 气质：活泼、喜欢探索。

#### 暖橙黄

- 主色：暖橙黄。
- 腹部：奶油白。
- 嫩芽：珊瑚粉。
- 气质：热情、爱鼓励人。

三种版本必须保持完全相同的轮廓、五官、比例和动作，仅换主色与嫩芽辅色。

## 3. 性格与表达

核心性格：

- 好奇，但不吵闹。
- 会为孩子的小进步开心。
- 不评价孩子聪明或笨。
- 不催促连续学习。
- 偶尔笨拙，增加亲近感，但不把失败当笑点。

推荐文案：

- “我们又学会一点啦。”
- “这颗星星是你认真练习得到的。”
- “先休息一下也可以，我会在这里。”
- “要不要一起复习一小关？”

禁止文案：

- “你再不来我就饿坏了。”
- “别人都升级了。”
- “连续学习不能断。”
- “答错了，宠物很失望。”

## 4. 形象条件检查

| 条件 | 当前描述是否满足 | 说明 |
|---|---|---|
| 低龄儿童可接受 | 是 | 圆润、短肢体、低攻击性 |
| 缩小后仍可识别 | 是 | 水滴轮廓 + 星形嫩芽是核心识别点 |
| 可承载配饰 | 是 | 头、颈、背、手均有清晰锚点 |
| 可制作简单动画 | 是 | 四肢短，动作形变成本低 |
| 不依赖文字/logo | 是 | 识别点来自轮廓 |
| 三种颜色可复用骨架 | 是 | 仅色彩变化 |
| 与学习主题有关 | 是 | 星光、嫩芽、成长含义 |
| 不像具体成熟 IP | 基本满足 | 生成和绘制时仍需做相似性人工检查 |
| 支持透明背景 | 是 | 无毛发、无半透明光效、无地面影子 |
| 适合分层穿戴 | 是 | 正面姿势和锚点明确 |

结论：当前形象描述符合首版条件，可以进入草图阶段。草图评审重点应放在“头顶嫩芽是否足够独特”和“水滴身体是否过于常见”。

## 5. 首版动作清单

### P0 必须

| 动作 | 用途 | 描述 |
|---|---|---|
| 正面待机 | 宠物小屋 | 轻微呼吸、眨眼、嫩芽小幅摆动 |
| 开心庆祝 | 学习奖励 | 双手举起，身体轻跳，嫩芽变亮；不加漂浮星星 |
| 吃东西 | 喂养 | 双手捧食物靠近嘴，脸颊轻鼓 |
| 玩球 | 玩耍 | 身体侧倾，短手推球；球必须与手接触 |
| 困倦 | 活力偏低 | 眼睛半闭，身体轻微下沉；不画漂浮 Z 字 |
| 想陪伴 | 心情偏低 | 双手放在身前，抬头期待，不流泪 |
| 升级 | 等级提升 | 身体伸展，腹部星点亮起，嫩芽张开 |

### P1 后续

- 戴上新配饰后的展示动作。
- 翻书/学习陪伴动作。
- 回访问候动作。
- 10 级成长阶段特殊待机。

## 6. 配饰锚点

所有配饰先基于“正面待机”制作：

| 槽位 | 锚点描述 | 避让要求 |
|---|---|---|
| 头部 | 两眼中心上方、嫩芽根部附近 | 不完全遮住嫩芽识别点 |
| 颈部 | 嘴下方到腹部上沿 | 不遮住嘴和手 |
| 背部 | 身体左右后侧 | 正面最多露出 25%-35% |
| 手持 | 右手外侧 | 必须与手接触，不悬空 |
| 房间 | 整体背景 | 中央保留宠物和弹层安全区 |

## 7. 首版配饰清单

### 7.1 头部

1. 星星发卡：黄色软胶小星星，带短蓝色卡扣。
2. 探索帽：浅卡其圆帽，帽檐短，不遮眼。
3. 小耳机：圆润蓝紫耳罩，无品牌标识。
4. 云朵睡帽：奶白软帽，顶部是贴合帽身的云朵结。

### 7.2 颈部

1. 薄荷领结：小尺寸双叶形领结。
2. 彩条围巾：蓝、黄、橙三色宽条，不使用品牌经典纹样。
3. 学习奖牌：圆形星芽图案，不写文字和数字。

### 7.3 背部

1. 小书包：圆角方形，正面只有星点和叶片图案。
2. 云朵披风：短披风，长度不过脚。
3. 探索小翅膀：叶片形软翼，不做天使羽毛。

### 7.4 手持

1. 星光笔：粗短安全笔造型，顶部星芽图案。
2. 小旗：纯图形旗面，无文字。
3. 放大镜：镜面不反射场景，边缘粗圆。

## 8. 食物和玩具

### 8.1 食物

- 星星饼干：五角轮廓必须圆润，不带糖霜文字。
- 云朵牛奶：小杯装，杯身只画云朵图案，不画吸管尖角。
- 彩虹果杯：三层软色果冻/水果块，颜色不超过 4 种。

### 8.2 玩具

- 弹弹球：蓝黄双色软球，无复杂花纹。
- 拼图积木：3 块大号圆角积木，不用幼儿窒息风险式真实小零件表达。
- 泡泡棒：环形手柄和短棒；泡泡动画不用半透明大面积特效时，可改为实体彩色小泡泡。

## 9. 场景物料

### 9.1 默认宠物小屋

描述：

- 像一间位于小行星上的温暖学习角。
- 背景使用浅蓝天空、奶油白墙面、薄荷色软垫。
- 左侧是圆角书架，右侧是小窗和星球远景。
- 中央地面保持干净，作为宠物动作区。
- 不展示可读文字、真实品牌、电子屏幕内容。
- 前景只放 1-2 件低矮物品，避免遮住宠物。

### 9.2 成长花园

- 10 级解锁背景。
- 夜蓝到紫色的柔和天空，地面有发光嫩芽，但光效必须贴合物体。
- 远处星球使用简单圆形，不画复杂宇宙写实纹理。

## 10. UI 图标

必须包含：

- XP。
- 星星积分。
- 饱腹。
- 心情。
- 活力。
- 喂养。
- 玩耍。
- 装扮。
- 商店。
- 成长手册。
- 已拥有。
- 已穿戴。
- 等级锁定。

风格：

- 圆角、实心为主。
- 2-3 个颜色。
- 不依赖细线。
- 24 px 下仍能辨认。
- 不用金币符号，积分统一用圆润星星。

## 11. 文件与规格建议

### 11.1 主形象

- 设计源文件：2048 x 2048。
- 导出：透明 PNG/WebP。
- 宠物小屋展示：建议 768 x 768。
- 商店/头像缩略图：256 x 256。

### 11.2 动画

- V1 每个动作 4-6 帧。
- 单帧统一画布与脚底基线。
- 透明背景。
- 不带地面影子、文字、速度线和漂浮符号。
- 配饰如需跟随动作，必须提供动作锚点或合成帧。
