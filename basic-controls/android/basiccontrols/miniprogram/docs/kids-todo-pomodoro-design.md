# 儿童向 · 每日任务 & 番茄钟 · 原型与设计方案

> 版本 v2.0 · 2026-06-08  
> 原则：**先可爱、再好用、最后才复杂**  
> 视觉母题：蓝天星球 · 云朵卡片 · 阳光贴纸 · 圆润控件

---

## 一、设计目标

| 维度 | 番茄钟 | 每日任务 |
|------|--------|----------|
| 气质 | 可爱专注小助手 | 实体打卡板的数字版 |
| 用户 | 6–12 岁孩子（家长可协助设置） | 同上 |
| 核心感受 | 「我在认真做一件事」 | 「打勾真开心，今天完成了！」 |
| 避免 | 黑底科幻屏、术语多、按钮小 | 列表像 Excel、删除误触、文字太成人 |

---

## 二、儿童 UX 规范（两模块共用）

### 2.1 触控

- 主按钮高度 ≥ **96rpx**，圆角 **999rpx（胶囊）**
- 可点击区域 ≥ **88×88rpx**（含滑块、拖拽柄）
- 重要操作（删除）必须 **二次确认**

### 2.2 文案

| 成人版 ❌ | 儿童版 ✅ |
|-----------|-----------|
| 重置今日任务 | 全部重来 |
| 预设 15 分钟 | 大概 15 分钟 |
| 倒计时已结束 | 时间到啦！休息一下吧 |
| 拖拽排序 | 按住左边点点，可以换顺序 |
| 添加任务 | 加一个任务 |

### 2.3 视觉

- 页面底：`#DDF4FF → #F9FDFF` 蓝天渐变
- 卡片：白底 + `2rpx #C8EAFF` 云边 + 轻阴影
- 主色：`#31A8FF` 天蓝 · 行动 `#FF9F43` 暖橙 · 完成 `#43CFC7` 青绿 · 未完成 `#FF6B7A` 软红
- 高亮：`#FFD166` 阳光黄（星星、进度、奖励感）
- 圆角：卡片 **32–40rpx**，按钮 **999rpx**
- 装饰：小云朵、小星星、可选 mascots（番茄君 / 打卡小星）

### 2.4 反馈

- 完成任务：滑块弹一下 + 行背景变浅绿
- 计时开始：表盘外圈缓慢呼吸光
- 时间到：全屏庆祝弹层 + 震动（可静音）

## 三、番茄钟 · 原型方案

### 3.1 信息结构

```
番茄钟页
├── 顶栏：← 番茄钟
├── 欢迎区（番茄君 + 一句话）
├── 主表盘（浅色可爱版，非黑底）
│   ├── 彩虹进度环（12 瓣，随时间点亮）
│   ├── 超大数字时间
│   └── 今天星期 / 日期
├── 时长快捷区（4 个大按钮，非 10 个小 chip）
│   └── 5分 · 15分 · 25分 · 30分
├── 模式切换：倒计时 ⇄ 正计时
├── 主操作：大橙按钮「开始专注」/「暂停一下」
└── 闹钟弹层：庆祝 + 「知道啦」
```

### 3.3 表盘设计（可爱实用）

| 元素 | 方案 |
|------|------|
| 底 | 浅云白 `#F6FBFF` 圆形，外圈 `#C8EAFF` 粗边（非黑底） |
| 进度 | 12 瓣彩虹花瓣，未完成半透明，已完成高亮 + 微光 |
| 数字 | `#1479D6` 粗体 LED 风格，**80rpx** |
| 装饰 | 表盘顶部小番茄 emoji / 图标，running 时轻轻摇摆 |
| 预设 | **4 个**大卡片式按钮，选中态天蓝底 + 阳光黄角标 |

### 3.4 实用细节

- 默认 **25 分钟**（标准番茄）
- 离开页面自动暂停（已有）
- 静音图标放在顶栏右侧，不抢主视觉
- 正计时模式：到达预设时长同样提醒（收工钟）

## 四、每日任务 · 原型方案

### 4.1 信息结构

```
每日任务页
├── 顶栏：← 每日任务 · 全部重来
├── 今日英雄区（进度 + 星星贴纸）
├── 任务卡片列表（每项一张「打卡条」）
│   ├── 序号圆标 / 完成变 ✓
│   ├── 任务名 + 时长标签
│   ├── 大滑块（✓ 绿 / ✗ 红）
│   └── 编辑（点文字）· 删除（需确认）
├── 底部大按钮：＋ 加一个任务
└── 添加/编辑弹层（大输入框 + 时长 picker）
```

### 4.2 线框原型

```
┌─────────────────────────────────────┐
│  ←  每日任务              全部重来   │
├─────────────────────────────────────┤
│  ┌───────────────────────────────┐  │
│  │  🌟 今日小任务                 │  │
│  │  已完成 2 / 7                  │  │
│  │  ⭐⭐☆☆☆☆☆  （星星进度）        │  │
│  │  明天还会看到同样的任务哦       │  │
│  └───────────────────────────────┘  │
│                                     │
│  ┌───────────────────────────────┐  │
│  │ ≡  ① 英语打卡    大概20分钟    │  │
│  │              [ ✓ | ● | ✗ ]    │  │
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │ ≡  ② 口算        大概15分钟    │  │
│  │              [ ✓ | ● | ✗ ]    │  │
│  └───────────────────────────────┘  │
│  ...                                │
│                                     │
│  ┌───────────────────────────────┐  │
│  │      ＋  加一个任务            │  │
│  └───────────────────────────────┘  │
│                                     │
│  💡 按住左边 ≡ 可以换顺序            │
└─────────────────────────────────────┘
```

### 4.3 儿童友好改造点

| 现状 | 改造 |
|------|------|
| 扁平列表行 | **独立圆角卡片**，行间有间距 |
| 小滑块 | 滑块加宽到 **180rpx**，旋钮 **56rpx** |
| 序号不显眼 | 左侧 **彩色数字圆标**，完成变绿色 ✓ |
| 进度条 | 改为 **星星贴纸**（7 个任务 = 7 颗星） |
| 删除 × 易误触 | 保留但缩小，**弹窗确认**（已有） |
| 添加在右上角 | 改为 **底部大按钮**，更好点 |
| 成人说明文字 | 换成短句、鼓励语气 |

### 4.4 打卡滑块（还原实体板）

- 左滑 / 点击 → **绿色 ✓**「完成啦」
- 右态 → **软红 ✗**「还没做」
- 切换时有 **0.2s 弹性动画**
- 完成卡片：浅绿底 `#E9FCF7` + 标题变深绿
