## 2. 背景与问题

学习星球已有音标、拼音、字词听写等模块，但家庭场景里还缺少一套**家长可自定义、孩子看得懂**的行为激励工具：

1. **规则不可配**：不同家庭对「好行为」定义不同，固定奖励表无法覆盖。
2. **反馈形式单一**：孩子更习惯小红花、小印章等具象符号，而不是抽象数字。
3. **目标周期缺失**：只有「今天加几分」，没有周目标、月目标、学期目标的连续感。
4. **规则容易失衡**：家长随手设「作业 +10、读书 +8」，可能一天轻松超过合理上限。

积分星球定位为**可配置的家庭积分板**，与学习模块解耦，也可在未来接入自动加分。

```text
家长制定规则（加分项 / 减分项 / 样式 / 日上限）
  -> 智能规则建议（按日上限校验是否合理）
  -> 设定周 / 月 / 学期目标
  -> 日常一键记录（或学习模块自动触发）
  -> 孩子查看积分墙、目标进度、流水
  -> 达成目标后兑换奖励 / 庆祝
```

## 3. 产品目标与非目标

### 3.1 V1 目标

- 每个孩子拥有独立的积分档案、规则集、目标与流水。
- 家长可**自行编辑**加分项、减分项（名称、分值、可选说明）。
- 支持 4 种积分样式作为**技术标准**：小红花、小印章、小星星、小心心。
- 设置「每日最多可积分数量」后，系统给出**规则合理性建议**。
- 提供**小学生日常生活**开箱模板（含八点半收工、学校/托管任务等）与简单礼物兑换。
- 支持制定**周目标、月目标、学期目标**，并展示进度。
- 提供积分首页、快速记录、规则管理、目标管理、流水页。
- 与学习模块联动为**可选增强**：完成听写/过关可触发预设加分项（不强制）。

### 3.2 成功指标

| 指标 | 观察目标 |
|---|---|
| 规则配置完成率 | 进入积分星球的家庭中，60% 完成至少 3 个加分项配置 |
| 日常记录率 | 已配置规则的家庭中，50% 每周至少记录 3 次 |
| 目标设定率 | 40% 家庭设定至少 1 个周期目标 |
| 孩子查看率 | 有记录的孩子中，70% 至少查看一次积分墙 |
| 规则建议采纳率 | 看到「规则建议」的家长中，30% 据此调整规则 |

### 3.3 V1 不做

- 充值、广告换积分、概率宝箱。
- 好友排行、班级排行、多人协作积分池。
- 云端同步、账号登录、老师端批量管理。
- 积分自动过期、因未学习而系统扣分（减分仅来自家长配置的减分项）。
- 复杂商城（实物、券码）；V1 仅虚拟庆祝与简单兑换。
- 修改设备时间刷分的云端校验（V1 仅本地去重 + 日上限）。

## 4. 产品原则

### 4.1 家长主导、孩子可见

- 规则制定、减分记录默认由家长操作（可开启「孩子申请加分，家长确认」V1.1）。
- 孩子侧强调**看得见的积累**：样式墙、目标进度、最近记录。
- 减分必须可解释，流水保留操作说明。

### 4.2 样式统一标准

四种积分样式为全模块统一视觉语言，不可混用为不同货币：

| 样式 ID | 名称 | 适用场景建议 |
|---|---|---|
| `flower` | 小红花 | 低年级、课堂表扬、日常好习惯 |
| `stamp` | 小印章 | 任务完成、打卡、契约感 |
| `star` | 小星星 | 学习成就、闯关、目标达成 |
| `heart` | 小心心 | 情绪关怀、亲子互动、品德类 |

一个家庭档案选定一种样式后，**所有积分记录统一展示**；切换样式不影响历史数值，只改变图标渲染。

### 4.3 日上限驱动规则设计

- 家长先设「每日最多可获得积分」（简称**日上限**），默认建议 **12**（见默认规则手册）。
- 系统根据已配置加分项，计算**理论最大日获得**并给出建议（见 §8.4）。
- 减分项不计入日上限，但单独展示「今日已扣」。
- 达到日上限后，加分项仍可记录但不再增加余额（可配置为禁止或提示）。

### 4.4 本地与分孩子

- 每个孩子独立：规则、样式、目标、余额、流水。
- 切换孩子后立即切换展示；删除孩子时同步删除全部积分数据。
- 规则可「从模板复制」到另一个孩子（V1.1）。

## 5. 核心概念

### 5.1 积分（points）

- 内部以**整数**存储，对外以选定样式图标展示，例如 `🌸 12`。
- 余额不为负；减分导致余额为 0 时停止继续扣减并提示。
- 不提供人民币购买入口。

### 5.2 加分项（bonus rule）

家长自定义条目，例如：

| 字段 | 示例 |
|---|---|
| 名称 | 按时完成作业 |
| 分值 | +2 |
| 每日次数上限 | 1 次（可选，空=不限） |
| 说明 | 18:00 前完成 |
| 启用 | 是 |

### 5.3 减分项（penalty rule）

| 字段 | 示例 |
|---|---|
| 名称 | 拖延睡觉 |
| 分值 | -1 |
| 每日次数上限 | 1 次 |
| 说明 | 22:30 后还在玩 |
| 启用 | 是 |

减分必须使用**独立减分项**，不允许在加分项里填负数。

### 5.4 流水（ledger）

每笔变动记录：

- 唯一 `recordId`
- 类型：`earn` / `spend` / `penalty`
- 关联规则 ID、分值、时间、操作人（parent/child/system）
- 本地最多保留 300 条

### 5.5 周期目标（goals）

| 类型 | 周期定义 | 典型目标值建议 |
|---|---|---|
| 周目标 | 自然周周一至周日 | 日上限 × 5 × 0.6 ~ 0.8 |
| 月目标 | 自然月 1 日至月末 | 周目标 × 4 × 0.9 |
| 学期目标 | 家长设定起止日期 | 月目标 × 4 ~ 5 |

目标包含：

- 目标名称（如「本周自律小达人」）
- 目标积分值
- 奖励说明（文字描述，V1 不做复杂商城）
- 进度 = 周期内净获得积分 / 目标值

### 5.6 规则健康度（rule health）

系统根据日上限与加分项配置，输出三档提示：

| 状态 | 条件 | 文案示例 |
|---|---|---|
| 偏宽松 | 理论最大日获得 > 日上限 × 1.3 | 「按现有规则，孩子最多一天可得 18 分，超过日上限 10，建议调低分值或减少项」 |
| 合理 | 日上限 × 0.7 ~ 日上限 × 1.3 | 「规则与日上限匹配，继续保持」 |
| 偏严格 | 理论最大日获得 < 日上限 × 0.5 | 「按现有规则很难达到日上限，可适当提高分值或增加加分项」 |

**理论最大日获得** = Σ(每个启用加分项的分值 × 其每日次数上限)；未设次数上限的项按 1 次计入保守估算。

## 6. 用户旅程

### 6.1 首次使用

```text
首页进入「积分星球」
  -> 引导页：选择积分样式（四选一）
  -> 设置日上限（默认 10，可调整）
  -> 从模板添加加分项 / 减分项（可跳过）
  -> 系统展示规则健康度建议
  -> 可选：设定第一个周目标
  -> 进入积分首页
```

### 6.2 日常记录

```text
积分首页点击「记一笔」
  -> 展示加分项 / 减分项网格（大按钮，适合家长快速点）
  -> 点击「按时完成作业 +2」
  -> 校验日上限、单项次数上限
  -> 动画反馈 + 更新余额与目标进度
  -> 写入流水
```

### 6.3 调整规则

```text
积分首页 -> 规则管理
  -> 编辑加分项 / 减分项
  -> 修改日上限
  -> 实时刷新规则健康度
  -> 保存后立即生效（不影响历史流水）
```

### 6.4 查看目标

```text
积分首页 -> 目标卡片（周 / 月 / 学期）
  -> 查看进度条与剩余天数
  -> 达成时全屏庆祝动画
  -> 标记「已兑换奖励」
```

## 8. 功能需求

### 8.1 学习星球首页入口

- 展示当前孩子积分余额，例如 `🌸 12`（随样式变化）。
- 点击进入 `pages/points-home/index`。
- 未创建孩子时隐藏或置灰。

### 8.2 积分首页

**顶部**

- 返回学习星球
- 当前孩子昵称
- 大号余额 + 样式图标

**今日摘要**

- 今日已获得 / 日上限（进度条）
- 今日已扣分数
- 「记一笔」主按钮

**周期目标**

- 最多同时展示 3 张目标卡片（各周期各 1 个活跃目标）
- 进度条 + 百分比 + 剩余天数

**积分墙**

- 最近 7 天获得的样式图标网格（最多 28 个）
- 点击「查看更多」进入流水

**快捷入口**

- 规则管理
- 目标管理
- 使用说明

### 8.3 快速记录页

**布局**

- Tab：加分 / 减分
- 网格卡片：名称 + 分值 + 样式图标
- 已触达单项日次数上限的项置灰
- 已触达日上限时，加分 Tab 顶部提示

**交互**

- 点击即记录，无需二次确认（减分可配置为需确认，默认开启确认）
- 成功：Toast + 轻动画（图标飞入积分墙）
- 失败：说明原因（日上限、次数上限、余额不足）

### 8.4 规则管理页

#### 8.4.1 积分样式

- 四选一：小红花 / 小印章 / 小星星 / 小心心
- 切换时预览首页效果
- 保存后立即生效

#### 8.4.2 日上限

- 范围：3 ~ 30，步进 1
- 默认：**12**（配合默认模板，普通日约得 6~9 分）
- 修改后重新计算规则健康度

#### 8.4.3 加分项 / 减分项 CRUD

| 操作 | 说明 |
|---|---|
| 新增 | 名称（必填，≤12 字）、分值（1~10）、每日次数上限（可选）、说明（可选） |
| 编辑 | 修改任意字段；已产生流水不受影响 |
| 删除 | 二次确认；历史流水中保留规则名称快照 |
| 启用/停用 | 停用后不出现在快速记录，历史保留 |
| 排序 | 长按拖拽（V1.1）；V1 按创建时间 |
| 选用模板 | 首次引导可选整包导入，见 `config/points-rule-templates.js` |

**内置模板包（首次可选用）**

| 模板 | 说明 |
|---|---|
| `primary_daily` | **默认推荐** · 小学生日常生活（14 加分 + 5 减分） |
| `minimal` | 精简三项，先试一周 |
| `learning_focus` | 学习强化，假期/冲刺 |

**默认推荐模板核心加分项**（完整表见 `docs/points-module-default-rules.md`）：

| 分类 | 示例 | 分值 |
|---|---|---:|
| 晚间收工 | **八点半前完成学习** | +3 |
| 学校 | 学校任务完成 / 超前 | +2 / +1 |
| 托管 | 托管任务完成 / **超量完成** | +2 / +2 |
| 习惯 | 阅读、整理书包、起床、家务、礼貌 | +1 |
| 学习星球（可选） | 听写、音标拼音、错字复习 | +1~+2 |

**默认减分项**（5 项，单日最多共 -4）：

- 拖延睡觉 -1 · 顶嘴不礼貌 -1 · 作业未完成 -2 · 说谎推责 -2 · 乱扔不整理 -1

**设计约束**：加分理论最大约 18/天，由日上限 12 截断；减分最多 -4/天，**正负约 3:1**，以乐趣和正向强化为主。

#### 8.4.3a 简单礼物兑换

配置见 `config/points-rewards-catalog.js`，家长线下兑现：

| 礼物 | 积分 | 类型 |
|---|---:|---|
| 自选睡前故事 | 15 | 体验 |
| 小零食一次 | 20 | 体验 |
| 周末多玩 30 分钟 | 30 | 体验 |
| 贴纸/小文具 | 40 | 实物 |
| 家庭电影夜 | 60 | 体验 |
| 亲子半日出游 | 100 | 体验 |
| 心愿单礼物 | 150 | 实物 |

兑换扣积分、写流水；部分体验奖设每周限兑 1 次（防通胀）。

#### 8.4.4 规则健康度面板

展示：

- 当前日上限
- 理论最大日获得
- 健康度状态（偏宽松 / 合理 / 偏严格）
- 一键建议：「将『按时完成作业』从 +3 调整为 +2」等（仅建议，不自动改）

**建议算法（产品口径）**

```text
理论最大 = sum(加分项.i.value * (加分项.i.dailyMax || 1))

if 理论最大 > 日上限 * 1.3:
  建议降低最高分值项或收紧 dailyMax
elif 理论最大 < 日上限 * 0.5:
  建议提高分值或增加加分项
else:
  规则合理
```

### 8.5 目标管理页

#### 8.5.1 周目标

- 每周可设 1 个活跃目标
- 默认建议值 = round(日上限 × 5 × 0.7)
- 新周开始时：旧目标归档，提示设定新目标或沿用

#### 8.5.2 月目标

- 每月 1 个活跃目标
- 默认建议值 = round(周目标 × 4 × 0.9)

#### 8.5.3 学期目标

- 家长设定开始/结束日期（如 2026-02-17 ~ 2026-07-04）
- 默认建议值 = round(月目标 × 4.5)
- 支持命名：「三年级上学期」

#### 8.5.4 目标字段

| 字段 | 说明 |
|---|---|
| 名称 | 如「本周自律星」 |
| 目标积分 | 正整数 |
| 奖励说明 | 如「周末多玩 30 分钟」 |
| 状态 | active / achieved / archived |

达成判定：周期内净获得积分 ≥ 目标值（周期内减分扣除后计算）。

### 8.6 积分流水页

- 时间、规则名称、分值（+ 绿色 / - 橙色）、操作来源
- 筛选：全部 / 加分 / 减分
- 空状态引导去「快速记录」

### 8.7 与学习模块联动（可选，V1 可后置）

若家长在某加分项开启「自动触发」并绑定事件：

| 学习事件 | 可绑定加分项示例 |
|---|---|
| 音标首次过关 | 学习进步 +2 |
| 听写完成 | 听写完成 +1 |
| 错字复习完成 | 认真复盘 +1 |

- 自动触发仍受日上限与单项次数上限约束。
- 流水标记 `operator: system`。

### 8.8 使用说明页

固定要点：

```text
积分规则由家长制定，孩子主要查看与感受成就感。
减分是为了建立边界，建议少而清晰，并和孩子事先沟通。
所有数据保存在本机，清理微信缓存会丢失。
四种样式只是展示不同，积分计算方式相同。
```

## 10. 边界与异常

| 场景 | 处理 |
|---|---|
| 日上限已满仍点加分 | 提示「今日已达上限」，不写入 |
| 减分超过余额 | 扣至 0，流水记录实际扣减量 |
| 删除孩子 | 同步删除 rules、goals、wallet、ledger |
| 切换孩子 | 加载对应孩子全套数据 |
| 规则删除后查流水 | 展示删除时快照名称 |
| 学期跨自然月 | 按设定起止日期统计，不拆月 |
| 设备时间回拨 | 当天记录仍归属原 dateKey；不重复计次靠 recordId |

## 11. 埋点与本地事件

V1 不上传，统一事件结构：

- `points_home_viewed`
- `points_recorded`（含 ruleId、delta）
- `points_rule_edited`
- `points_goal_achieved`
- `points_style_changed`
- `points_rule_health_viewed`

## 12. 版本规划

### V1：可配置积分板

- 四种样式标准、加减分项 CRUD、日上限、规则健康度。
- 快速记录、积分首页、流水。
- 周 / 月 / 学期目标。
- 首次引导与模板。

### V1.1：体验增强

- 孩子「申请加分」→ 家长确认。
- 规则复制到其他孩子。
- 目标达成分享卡片（本地生成图片）。
- 拖拽排序加分项。

### V2：与学习 / 宠物深度联动

- 学习事件自动触发加分项。
- 积分消费对接宠物商店。
- 云同步（账号方案确定后）。

## 13. 验收标准

### 规则配置

- 可新增、编辑、删除、启用/停用加分项与减分项。
- 四种样式可切换且全局一致展示。
- 日上限 3~30 生效；达到后不再加分。
- 规则健康度三种状态计算正确。

### 记录与流水

- 快速记录后余额、流水、今日摘要同步更新。
- 单项 dailyMax 生效。
- 减分不使余额为负。
- 删除孩子后数据不可恢复。

### 目标

- 周/月/学期目标进度随记录实时更新。
- 达成时触发庆祝态。
- 周期结束后目标自动归档。

### 体验

- 关键按钮触控区域 ≥ 44 × 44 px。
- 孩子视图无复杂编辑入口（规则管理需明确家长向）。
- 积分变动有文字说明。
