# 四平台统一发文方案（2026-06）

> **当前策略**：公众号、微博、知乎、CSDN **发同一篇全文**。不做短讯、不做「详情见公众号」类导流。

---

## 标准流程（每篇文章）

| 步骤 | 做什么 | 产出 |
|------|--------|------|
| 1 | 定稿 `index.md`，跑 `npm run convert` | `index.html` + `.docx` |
| 2 | **公众号** | 上传封面 → HTML 一键复制全文 |
| 3 | **知乎** | 粘贴 Markdown 全文 |
| 4 | **CSDN** | 粘贴 Markdown 全文 |
| 5 | **微博** | 粘贴全文（非短讯） |

预计每篇 **30～40 分钟**。

---

## 正文规范（四平台通用）

### 品牌落款（文首 + 文末）

```
技趣星球 · 用技术创造乐趣。
```

### 禁止出现

- `详情见公众号`、`公众号「AI技趣星球」`、`详情见链接`
- `关注 AI技趣星球`、`关注微信公众号`、`回复 XX`
- 微博短讯体（几条 bullet 引流到其他平台）
- 配图内的关注、回复、私信等导流词（见 `generate-images` SKILL）

### 跨文引用

用**纯文本文章名**，不用相对路径，不写「详见公众号某篇」。

---

## 分平台粘贴差异（仅格式，不改内容）

| 平台 | 差异 |
|------|------|
| 公众号 | 用 `index.html` 复制；图片走素材库 |
| 知乎 | 可改问句标题；正文不改 |
| CSDN | 保留代码块；补技术标签 |
| 微博 | 全文粘贴；标题同公众号 |

---

## 已弃用

- 微博短讯模板
- 各平台专属简版 / 改编版
- `npm run publish:post` 公网图链（暂无图床）
- 简媒 / Wechatsync 多平台一键分发

---

## 发布节奏（125 粉阶段）

| 类型 | 频率 |
|------|------|
| 长文 | 每 1～2 周 1 篇，四平台同步 |
| 热点 | 有则发，四平台同一篇 |

**原则**：一篇定稿，四处粘贴；不为某个平台单独改导流话术。
