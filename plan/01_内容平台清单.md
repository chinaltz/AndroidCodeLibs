# 技趣星球 - 博客发布平台清单

> 更新：2026-06-19  
> 范围：**当前仅维护 4 个发布平台**（公众号、微博、知乎、CSDN）

---

## ⭐ 当前发布平台（4 个）

| 平台 | 主页地址 | 发布形态 |
|------|---------|----------|
| **微信公众号** | https://mp.weixin.qq.com/ | **同一篇全文**；`index.html` 一键复制 |
| **微博** | https://weibo.com/ | **同一篇全文**（Markdown/富文本粘贴） |
| **知乎** | https://www.zhihu.com/ | **同一篇全文**；Markdown 导入 |
| **CSDN** | https://www.csdn.net/ | **同一篇全文**；保留代码块与配图 |

> **不做短讯、不做平台专属简版。** 四平台发同一篇文章，仅按各平台编辑器要求粘贴格式。

---

## 发布顺序（精简）

```
定稿 index.md → npm run convert
    → 四平台粘贴同一篇全文（顺序随意，建议公众号首发）
```

预计每篇 **30～40 分钟**（含四平台粘贴与配图上传）。

## 正文违禁表述（四平台统一）

以下词句**不得出现在公开正文**（含标题、摘要、配图内文字）：

| 类别 | 禁止写法 | 原因 |
|------|----------|------|
| 跨平台导流 | `详情见公众号`、`见公众号「…」`、`详情见链接` | 微博/知乎/CSDN 拒审 |
| 关注口令 | `关注 AI技趣星球`、`关注微信公众号`、`回复 XX` | 多平台统一发文时违规 |
| 短讯体 | 3 条 bullet +「详情见…」的微博专稿 | 已弃用，统一长文 |

**允许的品牌落款**（文首引用块 + 文末一行，四平台通用）：

```
技趣星球 · 用技术创造乐趣。
```
