技趣星球 · 用技术创造乐趣
开始前，先把风险说清楚

- 可能赚不了多少钱，甚至一分钱也赚不到。 收入取决于内容质量、账号基础、平台规则和推广任务，AiToEarn 只能减少重复操作，不能保证播放量和收入。
- 自动化操作有封号风险。 自动点赞、关注、评论、批量互动，可能触发平台风控，导致限流、功能限制甚至封号。
- 不要拿主账号测试。 已有大量粉丝、承担品牌或店铺收入的账号，尤其不要尝试自动互动。
- 国内平台风控通常更严格。 本文不建议在抖音、小红书、视频号等国内平台使用自动点赞、关注或批量评论。部分平台也不是没有风险。
- 只做 0 成本验证。 不买课、不投流、不租服务器，不为接任务提前交钱。遇到付费步骤先停下来。

本文只推荐使用内容创作、草稿整理、排期，以及人工检查后的发布。平台规则可能变化，操作前请再次确认。

你写完一条内容，准备发出去。

TikTok 要改成短视频节奏。

YouTube 要补标题、封面和简介。

Instagram 又要换尺寸和标签。

Facebook、X、Pinterest、LinkedIn……每个平台一套规矩。

发完一圈，半小时没了。

更麻烦的是，发完不等于有人看。评论要回，热点要跟，商家推广任务还要单独对接。

这就是 AiToEarn 想帮你省掉的那堆重复活。

它是一个开源的 AI 内容营销工具，可以帮你整理内容、连接多个平台、安排发布时间，也提供推广任务入口。

这不是“赚钱教程”。即使认真执行，也可能只能赚一点小钱，或者暂时没有收入。

我们只验证一件事：

不买课、不投流、不租服务器，能不能先做出一条部分内容，并获得真实播放、互动或订单？

这里的“0 成本”，指第一轮测试不额外购买服务。注册或操作时遇到付费步骤，先停下来，不影响验证思路。后续是否付费，等看到真实反馈再决定。

目标也不要定成“月入多少”。先连续发布 7-10 条内容，看看能否获得反馈。能赚到第一笔小额收入当然好；没有收入，也要得到播放、互动或选题数据。

如果准备尝试，建议优先选择 TikTok 或 YouTube Shorts。先跑通一个平台，再考虑 Instagram、Facebook、X、Pinterest 或 LinkedIn。

② 已经在用 Cursor 或 Claude？接上 MCP 更省事

难度：⭐⭐

AiToEarn 支持 MCP 协议。你可以把它理解为一根连接线：接好以后，可以在 AI 助手里调用 AiToEarn 的内容和发布能力。

如果你从没用过 Cursor、Claude Desktop 或 MCP，可以跳过这一节。网站入口已经够用。

前置条件

  • 已拿到 API Key（见上文）
  • Cursor 或 Claude Desktop 已安装

Cursor 配置步骤

  1. 打开 Cursor → Settings → MCP
  2. 添加一个新 MCP Server
  3. 填入下面信息（国内用户把地址换成 aitoearn.cn 版）：
MCP 地址：https://aitoearn.ai/api/unified/mcp
认证 Header：x-api-key: 你的API-Key
  1. 保存，看到 AiToEarn 工具列表出来就成功了

Claude Desktop 配置

找到 claude_desktop_config.json，加入：

{
 "mcpServers": {
 "aitoearn": {
 "type": "http",
 "url": "https://aitoearn.ai/api/unified/mcp",
 "headers": {
 "x-api-key": "你的API-Key"
 }
 }
 }
}

国内用户把 aitoearn.ai 换成 aitoearn.cn，Key 也要用国内站申请的。

配好后，你可以直接这样跟 AI 说

写内容并发出去：

3. 生成 5 个英文标签
4. 先保存草稿，不要直接发布

按 CPE 结算优先，列出任务名、要求和预估收益方式。

批量铺内容：

④ 想自己部署？Docker 三条命令

难度：⭐⭐⭐⭐

适合想把数据放到自己服务器的小团队。这条路通常会产生服务器成本，不属于本文推荐的 0 成本测试。

基础部署

git clone https://github.com/yikart/AiToEarn.git
cd AiToEarn
docker compose up -d

浏览器打开 http://localhost:8080 就能用。

需要平台授权时：配置 Relay

自己部署后，发布内容仍要登录对应平台。

按照项目官方文档，配置 Relay 后，可以通过 AiToEarn 的中继服务完成平台授权。是否使用这项服务，要根据自己的账号安全和数据要求决定。

在 docker-compose.yml 的 aitoearn-server 服务里加：

RELAY_SERVER_URL: https://aitoearn.ai/api
RELAY_API_KEY: 你的API-Key
RELAY_CALLBACK_URL: http://localhost:8080/api/plat/relay-callback

国内 Key 把 RELAY_SERVER_URL 改成 https://aitoearn.cn/api。

然后重启：

docker compose restart aitoearn-server

更完整的生产环境配置见仓库里的 DOCKER_DEPLOYMENT_CN.md。

推广任务怎么看

AiToEarn 提供推广任务入口。常见结算方式有三种：

模式含义适合
CPS按成交额结算带货、种草转化强的内容
CPE按互动量结算评论、点赞多的内容
CPM按播放量结算曝光型、流量型内容

看到任务先别急着接。至少检查四件事：

  • 产品是否与你的内容方向一致
  • 结算条件是否写清楚
  • 是否要求先交钱或购买不必要的服务
  • 是否需要授权超出任务范围的账号权限

遇到“先付费才能接单”、收益异常夸张或权限要求不合理的任务，直接跳过。

一条完整实操路径：0 成本测试部分平台

假设你刚开始做内容，每周能挤出 2 小时。先不买工具、不投广告，挑 TikTok 和 YouTube Shorts 中的一个测试。

第 1 步：注册 + 绑号（15 分钟）

打开 aitoearn.ai，注册，绑定一个部分平台账号。

第 2 步：用 Create 出 3 条草稿（20 分钟）

至少连续发 7-10 条内容，看到真实播放或互动后，再去任务市场看有没有合适的推广。没有反馈就先调整选题，不要花钱硬推。

常见误区和边界

误区 1：装完就能躺赚

AiToEarn 省的是重复操作时间，不是替你思考。

选题、人设、真实体验，还是得你来。AI 出的是草稿，不是成品。

误区 2：全自动互动可以无限刷

平台会识别异常互动。已有粉丝基础的账号、品牌账号和店铺账号，不要测试自动点赞、关注或批量评论。

尤其是国内平台，风控更严格，本文不建议使用此类自动化。可以让 AI 帮你整理评论和起草回复，但最后应由人确认并手动发送。

误区 3：所有平台一次搞定就完事

不同平台用户口味不同。AiToEarn 能帮你分发，但同一篇原文硬发十个平台，效果往往一般。

最好让它「一稿多改」，而不是「一稿多发」。

误区 4：变现任务来者不拒

CPS/CPE/CPM 任务要看账号调性。科技号去接美妆硬广，粉丝会跑。
