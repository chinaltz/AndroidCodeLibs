1. 添加孩子档案，进入首页

问答正文：

```text
问：不会小程序开发，能用 AI 做出听写工具吗？

答：可以，但你要负责把流程和需求说清楚。

我自己没有任何小程序开发经验，字词星球是我第一次写小程序。

做法很简单：把「选词 → 播报 → 批改 → 入库」每一步描述清楚，让 AI 实现，然后在真机上试。

AI 不能替你判断所有细节，比如：

- 播报间隔设多少合适
- 批改时到底标字还是标词
- 课文内容和学校是否一致

这些要家长自己试，试完再改。

错字入库规则：批改标错后自动进「在练错字」；同一字连续正确 3 次进「已掌握」。

数据存在手机本地，换机前务必导出备份。设置页 → 数据备份与恢复 → 导出并复制到剪贴板，存到备忘录即可。

如果你也想做类似小工具，先做一个最小流程跑通，比一上来堆功能实用得多。
```
