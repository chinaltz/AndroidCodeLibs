DeepSeek 接入
DeepSeek 降价后，别只拿来聊天

把 DeepSeek 接进编程 Agent

Reasonix 和 CodeWhale 怎么用？普通人照着这 5 张卡先跑起来。

难度：⭐⭐⭐ 终端工具 可照做
看完先做一个小练习：让 AI 读项目，不要一上来大改。
01
热点怎么用

降价的重点，不是“便宜几分钱”

真正的变化是：你可以把 DeepSeek 当成日常工具试错。

先记住这 3 件事
1API 像按字数收费的外包助理，价格低了，试错更轻。
2编程 Agent 会读项目、改文件、跑命令，不只是回答问题。
3普通人第一次试，先让它解释项目，别直接重构。
一句话：少研究参数，多让它帮你做一个小东西。
02
方法一

Reasonix：适合新手先稳稳跑起来

DeepSeek 官方文档里列出的终端编程 Agent，围绕 DeepSeek API 设计。

接入步骤
1安装 Node.js 20.10 或更高版本。
2进入一个练手项目目录。
3启动后按向导填写 DeepSeek API Key。
npx reasonix code
推荐第一问：先阅读项目，不要修改文件。
03
方法二

CodeWhale：适合喜欢终端的人

一个面向 DeepSeek V4 的开源终端编程工具，默认在项目目录里工作。

接入步骤
1用 npm、Homebrew、Cargo 或二进制安装。
2设置 DeepSeek API Key。
3在项目目录运行 codewhale。
npm install -g codewhale
适合小范围改 README、配置、脚本。
04
怎么选

别纠结工具，按场景选

选 Reasonix

第一次体验 DeepSeek 编程 Agent。想先让 AI 读项目、解释结构、一步步给计划。

选 CodeWhale

已经习惯终端。想在项目里快速问答、改文件、跑命令，并且能接受更多配置。

新手保命提示
✓每次只改一个小点。
✓改之前先给计划。
✓不要把 API Key 发给别人。
看完这 5 张，再选一个最小场景动手试。
