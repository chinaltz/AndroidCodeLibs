# 从拼音表到离线学习工具：拼音星球代码实现和真实演示

拼音表放进页面并不难。

难的是每一个拼音都要有正确数据、正确声调、可播放音频、独立进度，还要在断网时照常使用。

一句话结论：拼音星球的实现重点，是把内容数据、音频资源、拼读规则和孩子进度分开管理，再让四个页面组成完整学习闭环。

难度：⭐⭐⭐

## 代码结构先按功能边界拆开

拼音星球没有继续堆在原来的音标页面里。

它被放进独立分包，包含四个页面：

```text
拼音地图
单项学习
自由拼读
三题过关
```

这样做有两个直接好处。

第一，拼音代码不会影响已经稳定的音标和字词模块。

第二，音频资源可以跟着拼音分包加载，不占满主包空间。

基础按钮、卡片、顶部栏、进度条和音频播放工具仍然复用。

这像给新房间单独布置家具，但水电接口仍然使用同一套标准。

让 AI 规划目录时，可以这样问：

```text
我要在现有小程序中增加一个拼音学习分包。

现有项目已经有主题、按钮、卡片、音频播放和多孩子存储。
请设计目录结构，要求：
- 不复制基础组件
- 拼音页面和音频放在独立分包
- 数据、页面、音频清单分开
- 音标进度和拼音进度不能共用字段
```

目录先清楚，后面修改才不会互相牵连。

## 63 个学习项必须先通过数据检查

拼音内容不是直接写在 WXML 页面中。

每个学习项都是结构化数据，包括：

- 唯一 ID
- 类型
- 显示字母
- 所属区域
- 教学音频
- 发音提示
- 易混项
- 拼读示例

页面只负责展示数据。

新增或修改一个拼音项时，不需要重写页面布局。

更重要的是，构建前可以自动检查：

- 23 个声母是否完整
- 24 个韵母是否完整
- 16 个整体认读是否完整
- ID 是否重复
- 音频文件是否存在
- 示例是否有对应拼读数据

教育内容不能靠“页面看起来差不多”来验收。

数量和关联关系最好交给脚本检查。

## 声调不能靠随手替换字符串

把 `ma3` 显示成 `mǎ`，表面上像替换一个字母。

可真实标调有固定规则：

1. 有 `a`，优先标在 `a`
2. 没有 `a`，再找 `o` 或 `e`
3. `i` 和 `u` 同时出现，标在后一个
4. `ü` 要保留两点

所以代码中单独维护声调转换。

数据也同时保留数字声调、基础拼写和带调显示，避免不同页面各写一套。

检查这类规则时，可以让 AI 先生成测试用例：

```text
请为汉语拼音声调函数设计测试用例。

覆盖：
ma3、gui4、liu2、lüe4、shui3、yuan2。

每条写出输入、期望输出和对应标调规则。
不要修改代码，先检查规则是否完整。
```

先有期望结果，再写函数，出错时更容易定位。

## 自由拼读只允许真实存在的组合

自由拼读页会根据当前声母，列出可选韵母。

代码不是现场猜组合，而是读取人工核对的合法组合表。

孩子选择 `m + a` 后，可以继续切换四声，看到：

```text
mā  má  mǎ  mà
```

选择 `j + ü` 时，页面显示规范结果 `ju`，同时保留规则提示。

音频也不是在线临时生成。

只有资源包里存在的音节才显示可播放状态。

这样断网时仍然能听，也不会因为云接口额度、密钥或网络波动突然失效。

## 三题过关如何记录真实进度

每个拼音学习项有三步：

1. 听音选择字母
2. 根据字母选择拼读示例
3. 录音并回放对比

前两题可以判断对错。

第三题不做虚假的机器评分，只要求完成一次录音。

过关后，当前学习项加入这个孩子自己的完成列表。

如果已经完成过，再练一次不会重复增加完成数。

答错时记录学习项和次数，用于后续推荐易混音练习。

录音页面还要处理权限拒绝、停止录音、页面退出和临时文件失效等情况。

AI 可以写出主流程，但这些异常必须在真机上测试。

## 离线音频为什么单独做清单

音频文件不仅要“能响”，还要知道从哪里来。

项目为拼音音频保留了清单，记录：

- 文件用途
- 来源
- 许可证
- 采样率
- 声道
- 对应学习项

开发阶段可以使用许可证清楚的候选素材。

正式儿童产品最好使用同一位发音人录制，并由普通话老师抽听易混音。

音频统一为较小的单声道 MP3，减少分包体积。

完整素材不能不加筛选地全部塞进安装包。当前页面只开放已经内置音频的组合，后续补齐资源后再逐步增加。

## 真实功能演示可以怎么走

现在可以按这条路线实际体验：

1. 从学习星球首页进入拼音星球
2. 查看当前孩子的完成进度
3. 点击一个拼音卡，立即试听
4. 进入学习页查看发音提示和易混对比
5. 播放示例音节
6. 进入自由拼读，选择声母、韵母和声调
7. 完成听辨、拼读和录音三题
8. 返回地图查看完成状态
9. 切换孩子，确认进度独立
10. 断开网络，再检查核心音频是否正常播放

这十步比只录一段“页面滑动视频”更能证明功能真的可用。

## 今天的小结

今天只需要记住 4 件事：

- 学习内容要数据化，不能散落在页面里
- 拼读组合和声调规则必须有测试
- 音频资源要离线、可追溯、可检查
- 真实演示要覆盖进度、权限、切换孩子和断网
