## Agent 先一句话带过：它就是会帮你跑腿的 AI

你可以把普通 AI 聊天工具想成一个「会回答问题的人」。

你问一句，它答一句。

而 Agent 更像一个「会跑腿的人」。

你给它一个目标，它会自己拆成几步：

```text
理解你要做什么
 → 找需要的资料
 → 打开对应工具
 → 执行一些操作
 → 最后把结果交给你
```

比如你说：

```text
帮我把电脑里最近一个月的发票找出来，
按日期整理成一个表格，
再告诉我哪些可能还没报销。
```

普通聊天 AI 最多教你怎么找。

Agent 的目标是直接帮你找、整理、汇总。

这就是差别。

市面上的 Agent 后面我们可以专门写一篇。

它们不一定不好，但**更适合愿意折腾的人**：缺依赖、要 Key、命令行报错、卸载不干净……很多人还没体验到 Agent 能干啥，先被安装教育了一遍。

## 普通人可以先用 Marvis 做 5 件小事

第一次用，不要上来就让它「接管电脑」。

先从低风险任务开始。

### 1. 找文件

你可以这样问：

```text
帮我找一下电脑里最近 30 天的 PDF 文件，
优先找包含「合同」「发票」「报价」这些词的文件。
先列出文件名、位置和修改时间，
不要移动或删除任何文件。
```

### 2. 整理下载目录

你可以这样问：

```text
帮我分析一下下载目录里有哪些文件类型。
请按图片、文档、安装包、压缩包、其他来分类。
先给我整理建议，不要直接移动文件。
```

### 3. 总结文档

你可以这样问：

```text
请帮我阅读这份文档，
用普通人能看懂的话总结成 5 条重点。
如果里面有日期、金额、待办事项，请单独列出来。
```

### 4. 检查电脑状态

你可以这样问：

```text
帮我检查一下这台电脑最近可能变慢的原因。
请先看系统信息、磁盘空间、开机启动项。
只输出建议，不要直接修改设置。
```

### 5. 手机远程找电脑文件

如果你已经装了手机端，可以试试：

```text
帮我在电脑里找「报名表」相关文件，
如果找到多个，请按最近修改时间排序，
然后把最可能需要的那个发给手机。
```

这 5 件事都很适合新手。

因为它们不是高危操作。

先让 AI 看、找、列建议。

确认没问题，再让它执行。

## 使用 Marvis 时，记住 3 条安全规则

第一条：涉及删除、移动、修改文件时，一定让它先列计划。

你可以固定加一句：

```text
不要直接执行，先告诉我你准备怎么做，等我确认后再操作。
```

第二条：涉及支付、账号、密码、验证码，不要交给 AI。

AI 可以帮你找到入口、解释流程。

但最后确认，应该由你自己来。

第三条：重要文件先备份。

比如合同、发票、毕业论文、公司资料。

不要拿唯一一份原件做实验。

可以先复制一个测试文件夹。

让 Marvis 在测试文件夹里练手。

## 它适合谁？不适合谁？

适合这些人：

- 想体验 Agent，但不想折腾命令行的人
- 电脑文件很多，经常找不到东西的人
- 不熟悉系统设置，想用自然语言操作的人
- 想先免费试试 AI 助手的人
- 没有 IT 行业背景，但愿意一步步尝试的人

暂时不适合这些人：

- 想做复杂自动化流程的人
- 想完全替代程序员的人
- 公司资料高度敏感，又没有明确合规要求的人
- 希望 AI 一次性把所有电脑问题都解决的人

简单说：

> Marvis 更像入门级私人助理，不是万能替身。

你让它整理、搜索、总结、检查，它会更有用。

你让它全权接管一切，就容易出问题。
