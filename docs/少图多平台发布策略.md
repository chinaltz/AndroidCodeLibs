# 少图 + 多平台省时发布策略

> 公众号外链图不稳，各平台又要各自传图 → **默认少图、重排版**，把「必传图」压到最少。

## 核心原则

| 原则 | 说明 |
|------|------|
| **一张顶十张** | 只保留「没有图读者就懵」的图，其余用表格/ASCII/加粗列表 |
| **封面例外** | 公众号常需 1 张封面（后台传一次即可） |
| **正文零图也能发** | 知乎/掘金纯 Markdown 无图完全 OK |
| **不写平台专用两套正文** | 仍只维护一份 `index.md`，用排版代替配图 |

## 用什么代替插图？

| 代替方式 | 适合表达 | 多平台 |
|----------|----------|--------|
| **ASCII 框图 / 流程** | 步骤、关系、对照 | 全平台纯文本，公众号 HTML 已支持 |
| **Markdown 表格** | 工具对比、名词表、清单 | 全平台 |
| **加粗 + 短列表** | 要点、小结 | 全平台 |
| **引用块 `>`** | 注意、金句、合规说明 | 全平台 |
| **分隔线 `---`** | 章节切换 | 全平台 |
| **emoji（全文 ≤3）** | 章节标记 | 慎用，公众号也适用 |

**尽量少用**：场景示意图、装饰性头图、每节一张的「氛围图」。

## 每篇文章建议配图上限

| 类型 | 建议张数 | 说明 |
|------|----------|------|
| 扫盲 / 名词 / 观点文 | **0～1** | 可选 1 张封面；正文可无图 |
| 实操教程 | **1～3** | 封面 + 1 张总览图 + 最多 1 张关键界面截图 |
| 案例长文（如第一篇 7 场景） | **已偏多** | 新文尽量不超过 3 张正文图 |

## 多平台最省时的发布路径

### 路径 A：几乎无图（最快）

```
index.md（无图或仅封面在公众号后台单独传）
    ↓
npm run convert -- content/posts/<slug>     # 不必 upload:images
    ↓
知乎/掘金：直接导入 index.md
公众号：index.html 一键复制正文（纯文字+表格+ASCII）
封面：仅在公众号后台上传 1 张
```

**耗时**：基本不用图床、不用 `index.published.md`、不用逐张传正文图。

### 路径 B：有少量公网图（知乎等要图时）

```
index.md 控制在 1～3 张 ./images/
    ↓
npm run publish:post -- content/posts/<slug>   # SM.MS 批量一次上传
    ↓
知乎/掘金：index.published.md
公众号：index.html 复制正文 + 封面/裂图在后台补 1～2 张（Wechatsync 能省则省）
```

### 路径 C：Wechatsync 一键（图稍多但仍比手传快）

1. 用 `index.html` 或发布链接打开文章  
2. Wechatsync 勾选公众号、知乎、掘金等  
3. 插件尝试自动传图；失败项再在公众号后台补  

适合：仍想保留几张图，但不想每个平台各传一遍。

## 按平台拆分「最少操作」

| 平台 | 最少怎么做 |
|------|------------|
| **知乎 / 掘金 / CSDN** | 无图：导 `index.md`；有图：导 `index.published.md`（只上传一次 SM.MS） |
| **公众号** | 正文优先 **无图 HTML**；**封面 1 张** 必在后台传；正文图 0 张最省心 |
| **小红书 / 抖音** | 单独做 1 张竖版要点图（不塞进长文 MD，避免维护两套） |
| **Word 备份** | `convert` 即可，本地图自动嵌入 |

## 写作模板调整（技趣星球）

1. **开头**：生活场景 2～4 句 + 一句话结论（无需头图）  
2. **正文**：名词表 / 步骤用 **表格 + ASCII**，少「每节一图」  
3. **提示词**：代码块即可，不必配示意图  
4. **结尾**：小结列表 + 引流文字，无需配图  

`/generate-images` 默认只出 **封面 1 张 + 可选 1 张信息图**；其余用 ASCII 方案（见 skill）。

## 第一篇 vs 后续文

| 文章 | 现状 | 建议 |
|------|------|------|
| ai-for-ordinary-people | 图多 | 已发可不动；作参考时注意成本高 |
| ai-terms-plain-language | 计划 2 张 | 可改为 **0 张正文**，仅 ASCII 名词表 |
| 新文 | — | 默认 **≤3 张**，优先 0 张正文 |

## 检查清单（发布前 30 秒）

- [ ] 这张图删掉，读者是否仍看得懂？能 → 删  
- [ ] 能否用表格/ASCII 代替？能 → 不生成图  
- [ ] 公众号是否只靠封面也能点开？是 → 正文不传图  
- [ ] 是否已用 `publish:post` 批量上传（而非每个平台手传）？
