# 图片上传与多平台发布

> 没有腾讯云 COS 也能发。零基础推荐 **SM.MS 图床**；代码仓库公开可用 **GitHub**。

## 没有 COS，用哪个？

| 你的情况 | 推荐 | 费用 |
|----------|------|------|
| **没有云存储、想最快跑通** | **SM.MS** | 免费（有额度） |
| **GitHub 仓库是公开的** | **GitHub** | 免费 |
| **以后买了 OSS/COS** | `base-url` | 按量 |

下面按 **SM.MS** 写完整步骤（大多数人够用）。

---

## 方案 A：SM.MS（无 COS 首选）

### 1. 拿 Token

1. 打开 [https://sm.ms](https://sm.ms) 注册并登录  
2. 进入 **API Token** 页面，复制 Token  

### 2. 写配置

```bash
cp image-upload.config.example.json image-upload.config.json
```

编辑 `image-upload.config.json`：

```json
{
  "provider": "smms",
  "smms": {
    "token": "粘贴你的 SM.MS Token"
  }
}
```

也可用环境变量（不写进文件）：

```bash
export SM_MS_TOKEN="你的token"
```

### 3. 上传并生成发布稿

```bash
# 先预览（不真上传）
npm run upload:images -- content/posts/ai-terms-plain-language --dry-run

# 正式上传
npm run publish:post -- content/posts/ai-terms-plain-language
```

会得到：

- `index.published.md` — 图已是 `https://s2.loli.net/...` 这类公网链接  
- `index.html` — 公众号预览（外链图）  
- `*.docx` — Word 仍用本地图嵌入  

### 4. 各平台怎么用

| 平台 | 操作 |
|------|------|
| 知乎 / 掘金 / CSDN | 导入或粘贴 **`index.published.md`** |
| 公众号 | 浏览器打开 **`index.html`** → 一键复制；图显示不出则在后台传素材库 |
| 备份 | 用 **docx** 即可 |

### SM.MS 注意

- 单张图不宜过大（建议 &lt; 5MB）  
- 免费版有速率限制，文章图一般 10 张内没问题  
- 图床链接长期有效，但政策可能变，重要封面可自己留本地备份

## 方案 B：GitHub（仓库必须公开）

适合：项目已在 GitHub，且 **不介意图片进仓库**。

### 1. 创建 Token

GitHub → Settings → Developer settings → Personal access tokens → 勾选 `repo` 权限。

### 2. 配置

```json
{
  "provider": "github",
  "github": {
    "owner": "你的用户名",
    "repo": "AndroidCodeLibs",
    "branch": "main",
    "tokenEnv": "GITHUB_TOKEN"
  }
}
```

```bash
export GITHUB_TOKEN="ghp_xxxx"
npm run publish:post -- content/posts/ai-terms-plain-language
```

图片会提交到仓库，链接形如：

`https://raw.githubusercontent.com/用户/仓库/main/content/posts/.../images/header.png`

**私有仓库** raw 链接打不开，此方案不适用。

---

## 各平台为什么要公网图？

| 平台 | 本地 `./images/` | 公网 HTTPS |
|------|------------------|------------|
| 知乎 / 掘金 / CSDN | ❌ | ✅ |
| 公众号 | ❌ | ⚠️ 常需后台再传 |
| Word | ✅ 本地嵌入 | 不依赖图床 |

---

## 工作流（记住这一条）

```
index.md 写完 + images/ 配图齐
        ↓
npm run publish:post -- content/posts/<slug>
        ↓
用 index.published.md 发知乎/掘金
用 index.html 发公众号
```

## 文件说明

| 文件 | 作用 |
|------|------|
| `index.md` | 本地写稿，保留 `./images/` |
| `index.published.md` | 公网图链版，**对外发布用这个** |
| `images/upload-manifest.json` | 已上传记录，改图会重传 |
| `image-upload.config.json` | 图床配置（已在 .gitignore） |

---

## 以后若有 COS / OSS

在控制台上传 `images/` 后，把配置改成：

```json
{
  "provider": "base-url",
  "baseUrl": {
    "prefix": "https://你的域名/路径/images"
  }
}
```

脚本只替换 URL，不再调用 SM.MS。
