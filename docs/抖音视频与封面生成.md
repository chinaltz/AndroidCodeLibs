# 抖音视频与封面生成

文章定稿后，先生成 HTML / Word，再生成抖音发布素材。

## 一键生成

```bash
npm run build:video -- content/posts/[slug]
```

示例：

```bash
npm run build:video -- content/posts/ai-terms-plain-language
```

## 固定输出

命令会生成或更新：

```text
content/posts/[slug]/
└── social/
    ├── UPLOAD.md
    └── douyin/
        ├── douyin-summary-video.mp4
        ├── douyin-summary-video.with-audio.mp4
        ├── douyin-cover.png
        ├── douyin-script.md
        └── douyin-subtitles.srt
```

文件用途：

| 文件 | 用途 |
|------|------|
| `douyin-summary-video.with-audio.mp4` | 优先上传到剪映/抖音，带静音音轨 |
| `douyin-summary-video.mp4` | 无音轨备份版 |
| `douyin-cover.png` | 抖音封面 |
| `douyin-script.md` | 分镜、完整口播词、标题、发布文案 |
| `douyin-subtitles.srt` | 字幕文件，可导入剪映 |
| `UPLOAD.md` | 发布检查清单 |

## 剪映处理

1. 导入 `douyin-summary-video.with-audio.mp4`
2. 打开 `douyin-script.md`，复制“完整口播词”
3. 用剪映“文本朗读 / AI 配音”生成口播
4. 导入 `douyin-subtitles.srt`
5. 添加低音量 BGM
6. 导出 1080p、9:16、MP4

## 规则

- 如果已经存在 `douyin-script.md`，脚本只读取它，不覆盖人工定稿的口播词。
- 如果已经存在 `social/UPLOAD.md`，脚本不覆盖原有多平台清单。
- 视频画面和字幕时间来自 `douyin-script.md` 的“分镜脚本”表格。
- 如果新文章还没有 `douyin-script.md`，脚本会根据 `index.md` 自动生成一个基础版本，后续可以人工改口播。
