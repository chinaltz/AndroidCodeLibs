# 小学生英语音标学习软件 · 移动端一期原型

## 一期范围

一期只做两个闭环：

1. **48 个音标学习**
   - 学习地图按「短元音、长元音、双元音、清辅音、浊辅音、其他辅音」分组。
   - 采用国内小学/教培常用的 48 音标口径：20 个元音 + 28 个辅音，包含 `/tr/ /dr/ /ts/ /dz/` 这 4 个复合辅音。
   - 每个音标包含：标准发音、口型提示、3 个例词、3 步练习。
   - 单节学习控制在 3-5 分钟。

2. **过关检查**
   - 每学完一个音标进入 3 题检查。
   - 检查形式：听音辨认、看词选音标、跟读自评。
   - 结果只分 3 档：通过、接近、再练一次。

## 暂不做

- AI 语音精细诊断
- 家长端报告
- 教材同步词库
- 排行榜
- 会员付费
- 老师/班级端
- 大量自然拼读课程

这些放到二期以后，避免一期过重。

## 核心用户路径

```text
手机打开软件
  ↓
看到 48 音标学习地图
  ↓
选择一个未完成音标
  ↓
听标准音 + 看口型 + 读例词
  ↓
进入 3 题过关检查
  ↓
通过后点亮音标星星
```

## 设计方向

- 移动端优先，第一版按手机竖屏设计，不先做平板和桌面。
- 面向中国小学生，视觉要轻松、明亮、可爱，但不要幼儿化。
- 页面信息密度低，每屏只聚焦一个任务。
- 主色使用蓝绿，辅以橙色奖励色，避免整页单一蓝紫。
- 文案少讲术语，多说动作：张嘴、咧嘴、舌尖、轻轻送气。
- 按钮和关卡尺寸稳定，避免文字变化导致布局跳动。
