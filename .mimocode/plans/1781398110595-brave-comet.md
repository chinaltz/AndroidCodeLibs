# Plan: Generate 4-Panel Comic

## Objective
Generate a 4-panel comic (四格漫画) in the "Q萌搞笑风格" (Cute and funny style) about "程序员日常" (Programmer Daily Life) with Chinese dialogue bubbles.

## Content Specification
- **Theme**: Programmer Daily Life (程序员日常)
- **Style**: Q萌搞笑风格 (Round faces, thick lines, exaggerated expressions, similar to "桂宝")
- **Dialogue**: Chinese speech bubbles included
- **Panels**: 4 panels telling a funny story

### Draft Story (程序员日常)
1. **Panel 1**: Programmer excitedly starts work, coffee in hand, thinking "今天一定能准时下班！" (I'll definitely leave on time today!)
2. **Panel 2**: Boss appears with a "urgent" request: "这个需求很简单，今天能搞定吧？" (This requirement is simple, can you finish it today?)
3. **Panel 3**: Programmer is sweating, surrounded by floating code and error messages, thinking "简单...简单个鬼..." (Simple... simple my ass...)
4. **Panel 4**: Night time, programmer is still at desk, eyes glowing red, thinking "第 47 次修改...我觉得我快升天了" (47th revision... I think I'm ascending to heaven)

## Implementation Steps

### Step 1: Load `agnes-image-gen` Skill
Use the `agnes-image-gen` skill to generate the image.

### Step 2: Generate the Comic
Call the `agnes-image-2.1-flash` model with a detailed prompt:
```

第1格，程序员坐在电脑前喝咖啡，满面春风，气泡写「今天一定能准时下班！」；
第2格，老板走过来递文件，程序员惊讶，气泡写「这个需求很简单，今天能搞定吧？」；
第3格，程序员满头大汗，周围全是报错代码，气泡写「简单...简单个鬼...」；
第4格，深夜，程序员双眼通红盯着屏幕，气泡写「第 47 次修改...我觉得我快升天了」。
粗线条、明亮色彩、夸张表情，幽默温馨。
```
